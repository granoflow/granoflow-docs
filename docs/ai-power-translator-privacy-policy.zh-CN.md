本隐私政策适用于 **AI Power Translator** Chrome 扩展（以下简称“本扩展”）。
本扩展由 **A New Zero Innovations Limited（Hong Kong）**（以下简称“我们”）

这是针对本扩展的专项隐私政策。你另行选择使用 Granoflow 服务时，还适用
[Granoflow 隐私政策](https://granoflow.github.io/granoflow-docs/privacy-policy.zh-CN.html)。

## 1. 本扩展的单一用途

本扩展通过以下功能帮助你阅读和处理网页内容：翻译、解释和继续讨论文字；
在保留原文的情况下翻译网页可读文字；生成可选的阅读卡片；以及在你主动选择时
把卡片发送到 Granoflow 实例。

本扩展只会在提供这些面向用户的功能所必需的范围内处理网页内容及相关信息，
不会将这些信息用于广告、授信、数据经纪或与功能无关的用户画像。

## 2. 本扩展处理的信息

### 2.1 网页内容与当前页面信息

根据你选择的操作，本扩展可能处理：

- 你在网页上选中的文字
- 为理解所选文字而需要的当前段落及相邻文字
- 你请求全文翻译或解释时，当前页面中的可读文字
- 当前页面的标题、网址和域名
- 你的追问，以及回答追问所需的前文对话
- 根据上述内容生成的译文、解释和阅读卡片内容

本扩展不会访问 Chrome 的浏览历史数据库，也不会建立你访问过的全部网页记录。
当前页面网址和内容只用于你主动调用的功能、本地缓存标识、来源标注，以及你选择
发送到 Granoflow 的卡片。

### 2.2 设置与身份验证信息

本扩展可能保存你填写的以下设置：

- 目标语言和显示偏好
- AI API 地址、模型名称和 API 密钥
- 自动识别的 API 协议信息
- Granoflow 地址和可选的 Granoflow API 密钥

这些设置保存在你的 Chrome 配置文件的 `chrome.storage.local` 中，不会保存在
我们运营的服务器上。本扩展不会为这部分本地存储另加一层加密。

AI API 密钥只会在验证请求所必需时发送到你配置的 AI 地址。Granoflow 密钥只会
发送到你配置的 Granoflow 地址。

### 2.3 剪贴板

只有当你主动选择复制操作时，本扩展才会把文字写入剪贴板。本扩展不申请读取
剪贴板的权限。

### 2.4 我们不会通过本扩展收集的信息

本扩展不包含由开发者运营的使用分析、广告跟踪、崩溃报告或 AI 中转服务，也不
要求你为本扩展创建账户。你仅仅安装或使用本扩展，不会使我们收到你的网页内容、
提示词、API 密钥或本地缓存结果。

Google 可能依据其自身条款向发布者提供汇总后的 Chrome 应用商店统计数据。这些
商店统计数据不会向我们提供本扩展处理过的网页内容。

## 3. 信息在哪里处理

### 3.1 Chrome 内置 AI

当你选择 Chrome 内置 AI 且浏览器支持该功能时，文字由 Chrome 管理的设备端模型
处理。Chrome 可能需要先下载模型，但本扩展不会为了这种处理把你的提示词或网页
内容发送到我们的服务器。

Chrome 自身软件和服务的数据处理受 Google 的条款和隐私政策约束。

### 3.2 你配置的 AI 服务商

当你选择自定义 AI API 时，本扩展会把完成所请求功能所需的信息直接发送到你配置
的地址。根据所选操作，这些信息可能包括所选文字、上下文、当前页面网址、页面
标题、页面可读文字、追问、前文对话，以及生成卡片时使用的结果。

服务商还可能收到 IP 地址、请求元数据等常规网络信息。其数据保留、模型训练、
日志和安全做法由该服务商自己的条款和隐私政策约束。配置服务商前，请先查看这些
条款，也不要提交你不希望该服务商处理的信息。

远程 API 地址应使用 HTTPS。如果你配置了其他协议，本扩展会使用你提供的地址。
明文 HTTP 应仅用于不会把数据传到公共互联网的回环地址或其他本地服务。

### 3.3 Granoflow

发送卡片到 Granoflow 是可选功能，并且必须由你主动操作。你选择“发送到
Granoflow”后，本扩展可能向你配置的 Granoflow 地址发送所选卡片、原文、译文或
解释、来源网址、笔记标题和相关段落内容。

默认地址是你自己电脑上的回环地址。如果你把它改成其他地址，数据将发送到该目的
地，并受该 Granoflow 实例的安全和隐私做法约束。设置页还可能向所配置的
Granoflow 地址发出有限的连接检查请求；这些检查不包含网页内容。

本扩展不会自动把生成的卡片发送到 Granoflow。

## 4. 本地存储与保留时间

本扩展使用 `chrome.storage.local` 保存设置、缓存以及用于显示和发送的卡片：

- 译文、解释和生成卡片的缓存会在 72 小时内被复用。
- 72 小时是缓存有效期，不是保证删除期限。过期记录可能继续保留在本地，直到被
  新记录替换、因缓存容量限制被移除、从 Chrome 配置文件中清除，或者本扩展被
  卸载。
- 本地生成的笔记和卡片记录可能保留到扩展存储被清除或本扩展被卸载。
- 设置、API 密钥、地址信息和 Granoflow 连接设置会保留到你修改它们、清除扩展
  存储或卸载本扩展。
- 对话上下文只保留在当前扩展界面的对话过程中；我们不会故意把它加入由我们运营
  的独立长期对话历史服务。

清除普通网页 Cookie 或浏览历史不一定会清除扩展存储。你可以通过 Chrome 清除
本扩展的存储，或卸载本扩展，以删除本地保存的信息。

已经发送到 AI 服务商或非本地 Granoflow 实例的内容，适用该接收方自己的保留和
删除规则。

## 5. Chrome 权限

本扩展为已披露的功能申请以下权限：

- **网站访问权限（`<all_urls>`）**：显示划词工具栏；读取你要求翻译或解释的
  文字；插入全文译文；取得当前页面的来源信息；以及连接你配置的 AI 和
  Granoflow 地址。
- **`activeTab`**：支持与当前活动页面有关的操作。
- **`storage`**：在 Chrome 配置文件中保存设置、本地凭据、协议识别结果、缓存
  结果和生成的卡片信息。
- **`clipboardWrite`**：只在你选择复制操作后写入剪贴板。

本扩展不申请访问 Chrome 浏览历史、书签、联系人、精确位置、摄像头或麦克风。

## 6. 共享与披露

本扩展只会在以下情况下传输信息：

- 为完成你请求的翻译、解释、对话或卡片生成功能，发送到你配置的 AI 服务商
- 当你请求连接检查或主动发送卡片时，发送到你配置的 Granoflow 地址
- 为遵守适用法律，或防范恶意软件、垃圾信息、欺诈或滥用
- 在合并、收购或资产出售中，依照适用要求处理，包括在需要时事先取得你的明确
  同意

我们不会出售或出租本扩展的用户数据，也不会将其传输或用于个性化广告、重定向
广告、基于兴趣的广告、数据经纪、信用评估或贷款。

除非你为支持目的明确同意读取特定数据、为安全所必需、法律要求，或者数据已经
汇总和匿名化并用于允许的内部运营，否则我们不会允许人工读取本扩展的用户数据。
由于本扩展默认不会把网页内容发送到我们的服务器，我们通常也没有这类内容可供
查看。

## 7. Chrome 应用商店 Limited Use 要求

以下为 Google 官方要求的英文声明：

> The use of information received from Google APIs will adhere to the
> [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#userdata),
> including the Limited Use requirements.

即：对从 Google API 获得的信息的使用将遵守 Chrome 应用商店用户数据政策，
包括 Limited Use 要求。

具体而言，通过 Chrome 权限取得的信息只用于提供或改进本扩展已经披露的单一用途，
不会用于被禁止的广告、数据出售或无关用途。

## 8. 安全

本扩展尽量通过浏览器内处理，或直接发送到你配置的目的地，来减少开发者接触数据
的机会。你有责任保护自己的 Chrome 配置文件、API 密钥和所配置的服务。

远程 AI 地址应使用 HTTPS；请妥善保管 API 凭据。除非你信任所选处理方式和服务
商，否则不要翻译或解释敏感信息。任何存储或传输方式都无法保证绝对安全。

## 9. 你的选择与隐私请求

你可以：

- 在可用时选择 Chrome 内置 AI，而不是远程服务商
- 自行选择是否配置 AI 服务商和 Granoflow 实例
- 不在敏感内容上调用相关功能
- 修改或移除已保存的 API 密钥和地址
- 自行决定是否把卡片发送到 Granoflow
- 清除扩展存储或卸载本扩展

对于已经发送到你所选服务商的数据，请直接向该服务商提出查阅、更正或删除请求。
对于由我们控制的信息，请联系
[granoflow@anz.tv](mailto:granoflow@anz.tv)。请勿在公开 GitHub issues 中
发布 API 密钥、私人网页内容或其他敏感个人信息。
