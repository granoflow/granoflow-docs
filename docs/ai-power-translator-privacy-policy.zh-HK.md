本私隱政策適用於 **AI Power Translator** Chrome 擴充功能（下稱「本擴充
功能」）。本擴充功能由 **A New Zero Innovations Limited（Hong Kong）**
（下稱「我們」）營運。

這是針對本擴充功能的專項私隱政策。你另行選擇使用 Granoflow 服務時，亦適用
[Granoflow 私隱政策](https://granoflow.github.io/granoflow-docs/privacy-policy.zh-HK.html)。

## 1. 本擴充功能的單一用途

本擴充功能透過以下功能協助你閱讀和處理網頁內容：翻譯、解釋和繼續討論文字；
在保留原文的情況下翻譯網頁可讀文字；生成可選的閱讀卡片；以及在你主動選擇時
把卡片傳送到 Granoflow 實例。

本擴充功能只會在提供這些面向用戶的功能所必需的範圍內處理網頁內容及相關資料，
不會將這些資料用於廣告、授信、資料經紀或與功能無關的用戶分析。

## 2. 本擴充功能處理的資料

### 2.1 網頁內容與目前頁面資料

視乎你選擇的操作，本擴充功能可能處理：

- 你在網頁上選取的文字
- 為理解所選文字而需要的目前段落及相鄰文字
- 你要求全文翻譯或解釋時，目前頁面中的可讀文字
- 目前頁面的標題、網址和網域
- 你的跟進問題，以及回答問題所需的先前對話
- 根據上述內容生成的譯文、解釋和閱讀卡片內容

本擴充功能不會存取 Chrome 的瀏覽記錄資料庫，亦不會建立你曾瀏覽的所有網頁
記錄。目前頁面網址和內容只用於你主動啟用的功能、本機快取識別、來源標示，以及
你選擇傳送到 Granoflow 的卡片。

### 2.2 設定與認證資料

本擴充功能可能儲存你輸入的以下設定：

- 目標語言和顯示偏好
- AI API 位址、模型名稱和 API 金鑰
- 自動識別的 API 通訊協定資料
- Granoflow 位址和可選的 Granoflow API 金鑰

這些設定儲存在你的 Chrome 設定檔內的 `chrome.storage.local`，不會儲存在
我們營運的伺服器。本擴充功能不會為這部分本機儲存另加一層加密。

AI API 金鑰只會在驗證要求所必需時傳送到你設定的 AI 位址。Granoflow 金鑰只會
傳送到你設定的 Granoflow 位址。

### 2.3 剪貼簿

只有當你主動選擇複製操作時，本擴充功能才會把文字寫入剪貼簿。本擴充功能不申請
讀取剪貼簿的權限。

### 2.4 我們不會透過本擴充功能收集的資料

本擴充功能不包含由開發者營運的使用分析、廣告追蹤、當機報告或 AI 中轉服務，
亦不要求你為本擴充功能建立帳戶。你僅安裝或使用本擴充功能，不會使我們收到你的
網頁內容、提示詞、API 金鑰或本機快取結果。

Google 可能根據其條款向發佈者提供彙整後的 Chrome 線上應用程式商店統計資料。
這些商店統計資料不會向我們提供本擴充功能處理過的網頁內容。

## 3. 資料在哪裏處理

### 3.1 Chrome 內置 AI

當你選擇 Chrome 內置 AI 且瀏覽器支援該功能時，文字會由 Chrome 管理的裝置端
模型處理。Chrome 可能需要先下載模型，但本擴充功能不會為這種處理把你的提示詞
或網頁內容傳送到我們的伺服器。

Chrome 自身軟件和服務的資料處理受 Google 的條款和私隱政策約束。

### 3.2 你設定的 AI 服務供應商

當你選擇自訂 AI API 時，本擴充功能會把完成所要求功能所需的資料直接傳送到你
設定的位址。視乎所選操作，這些資料可能包括所選文字、上下文、目前頁面網址、
頁面標題、頁面可讀文字、跟進問題、先前對話，以及生成卡片時使用的結果。

服務供應商亦可能收到 IP 位址、要求中繼資料等一般網絡資料。其資料保留、模型
訓練、記錄和安全措施受該服務供應商自己的條款和私隱政策約束。設定服務供應商
前，請先查看這些條款，亦不要提交你不希望該服務供應商處理的資料。

遙距 API 位址應使用 HTTPS。如果你設定了其他通訊協定，本擴充功能會使用你提供
的位址。未加密的 HTTP 應只用於不會把資料傳到公共互聯網的迴路位址或其他本機
服務。

### 3.3 Granoflow

傳送卡片到 Granoflow 是可選功能，並且必須由你主動操作。你選擇「傳送到
Granoflow」後，本擴充功能可能向你設定的 Granoflow 位址傳送所選卡片、原文、
譯文或解釋、來源網址、筆記標題和相關段落內容。

預設位址是你自己電腦上的迴路位址。如果你把它改成其他位址，資料將傳送到該目的
地，並受該 Granoflow 實例的安全和私隱措施約束。設定頁亦可能向所設定的
Granoflow 位址發出有限的連線檢查要求；這些檢查不包含網頁內容。

本擴充功能不會自動把生成的卡片傳送到 Granoflow。

## 4. 本機儲存與保留時間

本擴充功能使用 `chrome.storage.local` 儲存設定、快取，以及用於顯示和傳送的
卡片：

- 譯文、解釋和生成卡片的快取會在 72 小時內被重用。
- 72 小時是快取有效期，不是保證刪除期限。過期記錄可能繼續保留在本機，直至被
  新記錄取代、因快取容量限制被移除、從 Chrome 設定檔清除，或本擴充功能被
  移除。
- 本機生成的筆記和卡片記錄可能保留至擴充功能儲存空間被清除，或本擴充功能被
  移除。
- 設定、API 金鑰、位址資料和 Granoflow 連線設定會保留至你修改它們、清除擴充
  功能儲存空間或移除本擴充功能。
- 對話上下文只保留在目前擴充功能介面的對話過程；我們不會刻意把它加入由我們
  營運的獨立長期對話記錄服務。

清除一般網頁 Cookie 或瀏覽記錄未必會清除擴充功能儲存空間。你可以透過 Chrome
清除本擴充功能的儲存空間，或移除本擴充功能，以刪除本機儲存的資料。

已傳送到 AI 服務供應商或非本機 Granoflow 實例的內容，適用該接收方自己的保留
和刪除規則。

## 5. Chrome 權限

本擴充功能為已披露的功能申請以下權限：

- **網站存取權限（`<all_urls>`）**：顯示劃詞工具列；讀取你要求翻譯或解釋的
  文字；插入全文譯文；取得目前頁面的來源資料；以及連接你設定的 AI 和
  Granoflow 位址。
- **`activeTab`**：支援與目前使用中頁面有關的操作。
- **`storage`**：在 Chrome 設定檔中儲存設定、本機憑證、通訊協定識別結果、
  快取結果和生成的卡片資料。
- **`clipboardWrite`**：只在你選擇複製操作後寫入剪貼簿。

本擴充功能不申請存取 Chrome 瀏覽記錄、書籤、聯絡人、精確位置、相機或咪高峰。

## 6. 分享與披露

本擴充功能只會在以下情況傳送資料：

- 為完成你要求的翻譯、解釋、對話或卡片生成功能，傳送到你設定的 AI 服務供應商
- 當你要求連線檢查或主動傳送卡片時，傳送到你設定的 Granoflow 位址
- 為遵守適用法律，或防範惡意軟件、垃圾訊息、欺詐或濫用
- 在合併、收購或資產出售中，按照適用要求處理，包括在需要時事先取得你的明確
  同意

我們不會出售或出租本擴充功能的用戶資料，亦不會將其傳送或用於個人化廣告、
重新定位廣告、興趣廣告、資料經紀、信貸評估或貸款。

除非你為支援目的明確同意讀取特定資料、為安全所必需、法律要求，或資料已彙整和
匿名化並用於獲准的內部運作，否則我們不會允許人工讀取本擴充功能的用戶資料。
由於本擴充功能預設不會把網頁內容傳送到我們的伺服器，我們一般亦沒有這類內容
可供查看。

## 7. Chrome 線上應用程式商店 Limited Use 要求

以下為 Google 官方要求的英文聲明：

> The use of information received from Google APIs will adhere to the
> [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#userdata),
> including the Limited Use requirements.

即：使用從 Google API 收到的資料時，將遵守 Chrome 線上應用程式商店用戶資料
政策，包括 Limited Use 要求。

具體而言，透過 Chrome 權限取得的資料只用於提供或改進本擴充功能已披露的單一
用途，不會用於被禁止的廣告、資料出售或無關用途。

## 8. 安全

本擴充功能盡量透過瀏覽器內處理，或直接傳送到你設定的目的地，以減少開發者接觸
資料的機會。你有責任保護自己的 Chrome 設定檔、API 金鑰和所設定的服務。

遙距 AI 位址應使用 HTTPS；請妥善保管 API 憑證。除非你信任所選處理方式和服務
供應商，否則不要翻譯或解釋敏感資料。任何儲存或傳輸方式都無法保證絕對安全。

## 9. 你的選擇與私隱要求

你可以：

- 在可用時選擇 Chrome 內置 AI，而不是遙距服務供應商
- 自行選擇是否設定 AI 服務供應商和 Granoflow 實例
- 不在敏感內容上啟用相關功能
- 修改或移除已儲存的 API 金鑰和位址
- 自行決定是否把卡片傳送到 Granoflow
- 清除擴充功能儲存空間或移除本擴充功能

對於已傳送到你所選服務供應商的資料，請直接向該服務供應商提出查閱、更正或刪除
要求。對於由我們控制的資料，請聯絡
[granoflow@anz.tv](mailto:granoflow@anz.tv)。請勿在公開 GitHub issues
發佈 API 金鑰、私人網頁內容或其他敏感個人資料。
