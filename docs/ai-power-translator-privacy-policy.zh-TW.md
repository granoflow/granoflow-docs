本隱私權政策適用於 **AI Power Translator** 的 Chrome、Microsoft Edge 瀏覽器擴充功能，以及 macOS 和 iOS 上的 Safari App（以下稱「本擴充
功能」）。本擴充功能由 **A New Zero Innovations Limited（Hong Kong）**
（以下稱「我們」）營運。

這是針對本擴充功能的專屬隱私權政策。你另外選擇使用 Granoflow 服務時，亦適用
[Granoflow 隱私權政策](https://granoflow.github.io/granoflow-docs/privacy-policy.zh-TW.html)。

本產品也支援圖片及線上或本機 PDF 翻譯。選擇雲端模型時，所需圖片、PDF 文字或影像會直接傳送至你設定的模型服務；裝置端功能可用時則在本機處理。具體能力與隱私條件取決於所選處理方式。

## 1. 本擴充功能的單一用途

本擴充功能透過以下功能協助你閱讀和處理網頁內容：翻譯、解釋和繼續討論文字；
在保留原文的情況下翻譯網頁可讀文字；產生可選的閱讀卡片；以及在你主動選擇時
將卡片傳送到 Granoflow 執行個體。

本擴充功能只會在提供這些面向使用者的功能所必要的範圍內處理網頁內容及相關
資訊，不會將這些資訊用於廣告、授信、資料仲介或與功能無關的使用者分析。

## 2. 本擴充功能處理的資訊

### 2.1 網頁內容與目前頁面資訊

依你選擇的操作，本擴充功能可能處理：

- 你在網頁上選取的文字
- 為理解所選文字而需要的目前段落及相鄰文字
- 你要求全文翻譯或解釋時，目前頁面中的可讀文字
- 目前頁面的標題、網址和網域
- 你的後續問題，以及回答問題所需的先前對話
- 根據上述內容產生的譯文、解釋和閱讀卡片內容

本擴充功能不會存取 瀏覽器的瀏覽記錄資料庫，也不會建立你造訪過的所有網頁
記錄。目前頁面網址和內容只用於你主動啟用的功能、本機快取識別、來源標示，以及
你選擇傳送到 Granoflow 的卡片。

### 2.2 設定與驗證資訊

本擴充功能可能儲存你輸入的以下設定：

- 目標語言和顯示偏好
- AI API 網址、模型名稱和 API 金鑰
- 自動辨識的 API 通訊協定資訊
- Granoflow 網址和選用的 Granoflow API 金鑰

這些設定透過 `chrome.storage.local` API 儲存在瀏覽器設定檔或 Safari App 的本機儲存空間，
不會儲存在我們營運的伺服器。本擴充功能不會為這部分本機儲存另加一層加密。

AI API 金鑰只會在驗證要求所必要時傳送到你設定的 AI 網址。Granoflow 金鑰只會
傳送到你設定的 Granoflow 網址。

### 2.3 剪貼簿

只有當你主動選擇複製操作時，本擴充功能才會將文字寫入剪貼簿。本擴充功能不申請
讀取剪貼簿的權限。

### 2.4 我們不會透過本擴充功能蒐集的資訊

本擴充功能不包含廣告追蹤、當機回報或 AI 中繼服務，
也不要求你為本擴充功能建立帳號。你僅安裝或使用本擴充功能，不會使我們收到你的
網頁內容、提示詞、API 金鑰或本機快取結果。

Google 可能依其條款向發布者提供彙整後的 Chrome 線上應用程式商店統計資訊。
這些商店統計資訊不會向我們提供本擴充功能處理過的網頁內容。

### 2.5 產品使用統計（Firebase）

使用統計在安裝及每次擴充功能升級後預設開啟。你可在一般設定中關閉，關閉不影響翻譯。
關閉會停止自動蒐集、清空待傳送資料並取消傳送中的請求；保持關閉直到下次安裝或升級重新開啟。
開啟時，擴充功能向產品獨立 Firebase 專案傳送每日首次翻譯次數、擴充功能內推廣顯示和點擊
次數、標準化模型來源、選擇與呼叫類別，以及可取得的數字 token 總計。共同欄位包括瀏覽器
名稱和主要版本、擴充功能版本、本地日期、協定版本及每次上傳新產生的隨機批次 ID；不重用為
使用者或安裝身分。模型語言差異回報在接收服務允許時，只包含受控檔案 ID/版本、標準化服務
和模型類別、用途、來源/目標語言代碼及差異分類。

這些事件不含網頁文字、圖片、PDF、提示詞、金鑰、自訂端點、私有模型名稱、原始設定、
錯誤原文或完整 User-Agent。使用 Firestore REST，不載入 Firebase Analytics、廣告追蹤或
自動網頁蒐集 SDK，不建立匿名登入使用者 ID，也不關聯跨網站或跨產品身分，不用於個人化廣告。
擴充功能不會把 IP 寫入這些事件；Google 基礎設施可能處理 IP 等連線資訊，遵循
[Firebase 隱私規則](https://firebase.google.com/support/privacy)。

維護工作按設計將超過 30 天的原始紀錄彙總後刪除，超過 12 個月的每日彙總刪除。維護在開發者
電腦執行；電腦離線、磁碟未掛載、登入失效或服務無法連線時會延後，不能保證第 30 天準時刪除。
Google 基礎設施日誌按 Google 政策處理。由於沒有持續安裝身分，已提交事件無法憑安裝 ID
找回。網站改善建議連結只開啟作者的 X 首頁，不會自動向 Firebase 提交目前網站或其內容。

## 3. 資訊在哪裡處理

### 3.1 裝置端 AI

當你選擇 Chrome 內建 AI 且瀏覽器支援該功能時，文字會由 Chrome 管理的裝置端
模型處理。Chrome 可能需要先下載模型，但本擴充功能不會為這種處理將你的提示詞
或網頁內容傳送到我們的伺服器。

Chrome 本身軟體和服務的資料處理受 Google 的條款和隱私權政策約束。

在 macOS 和 iOS 的 Safari 中，裝置及語言支援時可使用 Apple 的 Translation 框架或 Foundation Models 在裝置上處理文字。系統可能下載所需模型；此處理不會將網頁內容或提示詞傳送到我們的伺服器。Apple 軟體和服務遵循 Apple 的條款及隱私權政策。

### 3.2 你設定的 AI 服務供應商

當你選擇自訂 AI API 時，本擴充功能會將完成所要求功能所需的資訊直接傳送到你
設定的網址。依所選操作，這些資訊可能包括所選文字、上下文、目前頁面網址、頁面
標題、頁面可讀文字、後續問題、先前對話，以及產生卡片時使用的結果。

服務供應商也可能收到 IP 位址、要求中繼資料等一般網路資訊。其資料保留、模型
訓練、記錄和安全措施受該服務供應商自己的條款和隱私權政策約束。設定服務供應商
前，請先查看這些條款，也不要提交你不希望該服務供應商處理的資訊。

遠端 API 網址應使用 HTTPS。如果你設定了其他通訊協定，本擴充功能會使用你提供
的網址。未加密的 HTTP 應只用於不會將資料傳到公共網際網路的回送位址或其他本機
服務。

### 3.3 Granoflow

傳送卡片到 Granoflow 是選用功能，且必須由你主動操作。你選擇「傳送到
Granoflow」後，本擴充功能可能向你設定的 Granoflow 網址傳送所選卡片、原文、
譯文或解釋、來源網址、筆記標題和相關段落內容。

預設網址是你自己電腦上的回送位址。如果你將它改成其他網址，資料將傳送到該目的
地，並受該 Granoflow 執行個體的安全和隱私措施約束。設定頁也可能向所設定的
Granoflow 網址發出有限的連線檢查要求；這些檢查不包含網頁內容。

本擴充功能不會自動將產生的卡片傳送到 Granoflow。

## 4. 本機儲存與保留時間

本擴充功能使用 `chrome.storage.local` 儲存設定、快取，以及用於顯示和傳送的
卡片：

- 譯文、解釋和產生卡片的快取會在 72 小時內被重複使用。
- 72 小時是快取有效期，不是保證刪除期限。過期記錄可能繼續保留在本機，直到被
  新記錄取代、因快取容量限制被移除、從瀏覽器或 Safari App 清除，或本擴充功能被
  移除。
- 本機產生的筆記和卡片記錄可能保留至擴充功能儲存空間被清除，或本擴充功能被
  移除。
- 設定、API 金鑰、網址資訊和 Granoflow 連線設定會保留至你修改它們、清除擴充
  功能儲存空間或移除本擴充功能。
- 對話上下文只保留在目前擴充功能介面的對話過程；我們不會刻意將它加入由我們
  營運的獨立長期對話記錄服務。

清除一般網頁 Cookie 或瀏覽記錄不一定會清除擴充功能儲存空間。你可以透過瀏覽器或裝置
清除本擴充功能的儲存空間，或移除本擴充功能，以刪除本機儲存的資訊。

已傳送到 AI 服務供應商或非本機 Granoflow 執行個體的內容，適用該接收方自己的
保留和刪除規則。

## 5. 瀏覽器及 Safari 權限

Chrome 和 Edge 申請下列權限；Safari 透過 Apple 的 App 和擴充功能權限設定授予相應存取權限。

- **網站存取權限（`<all_urls>`）**：顯示選字工具列；讀取你要求翻譯或解釋的
  文字；插入全文譯文；取得目前頁面的來源資訊；以及連接你設定的 AI 和
  Granoflow 網址。
- **`activeTab`**：支援與目前使用中頁面有關的操作。
- **`storage`**：在本機儲存設定、本機憑證、通訊協定辨識結果、
  快取結果和產生的卡片資訊。
- **`clipboardWrite`**：只在你選擇複製操作後寫入剪貼簿。

本擴充功能不申請存取 Chrome 瀏覽記錄、書籤、聯絡人、精確位置、相機或麥克風。

## 6. 分享與揭露

本擴充功能只會在以下情況傳送資訊：

- 使用統計開啟時，向 Firebase 傳送第 2.5 節列出的產品互動統計

- 為完成你要求的翻譯、解釋、對話或卡片產生功能，傳送到你設定的 AI 服務供應商
- 當你要求連線檢查或主動傳送卡片時，傳送到你設定的 Granoflow 網址
- 為遵守適用法律，或防範惡意軟體、垃圾訊息、詐欺或濫用
- 在合併、收購或資產出售中，依照適用要求處理，包括在需要時事先取得你的明確
  同意

我們不會出售或出租本擴充功能的使用者資料，也不會將其傳送或用於個人化廣告、
再行銷廣告、興趣廣告、資料仲介、信用評估或貸款。

除非你為支援目的明確同意讀取特定資料、為安全所必要、法律要求，或資料已彙整和
匿名化並用於獲准的內部營運，否則我們不會允許人工讀取本擴充功能的使用者資料。
由於本擴充功能預設不會將網頁內容傳送到我們的伺服器，我們通常也沒有這類內容
可供查看。

具體而言，透過 Chrome 權限取得的資訊只用於提供或改進本擴充功能已揭露的單一
用途，不會用於被禁止的廣告、資料出售或無關用途。

## 8. 安全

本擴充功能盡量透過瀏覽器內處理，或直接傳送到你設定的目的地，以減少開發者接觸
資料的機會。你有責任保護自己的瀏覽器設定檔或 Apple 裝置、API 金鑰和所設定的服務。

遠端 AI 網址應使用 HTTPS；請妥善保管 API 憑證。除非你信任所選處理方式和服務
供應商，否則不要翻譯或解釋敏感資訊。任何儲存或傳輸方式都無法保證絕對安全。
