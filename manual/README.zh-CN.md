# Granoflow 手册

Granoflow 帮你把任务、项目、回顾和记忆卡片放在同一个工作流里。你可以先把要做的事收进任务列表，再把阶段性工作放进项目和里程碑；完成之后，用回顾和卡片把经验留下来，下一次遇到类似事情时，不必从零开始。

这份手册按真实界面和已审核截图编写。当前首版先覆盖卡片学习相关页面，因为它最能说明 Granoflow 的一个核心想法：任务不是做完就消失，里面值得复用的判断、经验和问题，可以继续沉淀成以后能回看的材料。

## 先完成一次卡片学习

**文档类型：Tutorial**  
**读者目标：**从一张固定的示例卡片开始，理解卡片学习页的提问态、答案态和评分按钮。  
**完成标准：**你能打开一张卡片，先看问题，再显示答案，并选择一个符合当下熟悉程度的评分。

当你第一次看到“卡片练习”时，可以先把它理解成一个很小的复用动作：把一个你在任务、项目或回顾里想明白的问题，变成以后能再次提取的提示。它不是要你背诵每一句话，而是让某个判断在下一次工作时更容易被想起。

下面这张示例卡片问的是“什么是领域？”。这里的领域可以理解为你长期在照顾的生活或工作方向，例如工作、学习、关系、身体和休闲。它提醒你：任务不是一堆孤立杂物，它们通常属于更大的方向。

![卡片练习的问题态：页面中央显示“什么是领域？”，底部只有显示答案按钮。](/manual/screenshots/zh-cn/review-card-study-domain-garden-question.png)

1. 打开卡片练习页面后，先只看问题。
2. 先用自己的话回答，不急着点开答案。
3. 点击 **显示答案**。

点击后，页面会从问题态进入答案态。你会看到卡片背面的解释，以及底部几个评分按钮。

![卡片练习的答案态：页面显示领域说明，底部有遗忘、勉强、记得和轻松。](/manual/screenshots/zh-cn/review-card-study-domain-garden.png)

评分不需要追求“好看”。它只是记录你这一次提取答案的感觉：

- **遗忘**：刚才想不起来，适合尽快再看。
- **勉强**：有印象，但还不稳定。
- **记得**：能顺利想起主要意思。
- **轻松**：不用费力就能说清楚。

如果你不确定选哪个，先选更贴近真实感受的那个。Granoflow 更需要真实反馈，而不是漂亮记录。等你用几次之后，卡片会帮助你看见：哪些想法已经变得熟悉，哪些仍然需要回到任务和项目里继续练。

## 查看卡片统计

**文档类型：Reference**  
**读者目标：**知道统计页显示什么，以及它能帮助你判断哪类卡片需要继续练习。  
**完成标准：**你能从统计页看出卡片总量、今日练习情况和学习状态分布。

统计页适合用来快速判断卡片库是不是还在正常运转。它不要求你每天追逐数字，而是让你知道：现在有多少卡片，今天练过多少，哪些卡片还在学习中，哪些已经比较稳定。

![卡片统计页面显示总卡片数、今日练习和不同学习状态的概览。](/manual/screenshots/zh-cn/review-card-statistics-main.png)

你可以这样读这页：

- **总卡片数**：当前可用于学习和回看的卡片数量。
- **今日已练习**：今天已经完成的练习数量。
- **未学习 / 学习中 / 已掌握 / 已内化**：帮助你区分卡片处在什么阶段。

如果统计数字和你预期不同，先检查是否切到了正确的账号、设备和语言环境，再进入卡片管理页查看具体卡片。

## 管理卡组和卡片

**文档类型：How-to**  
**读者目标：**找到卡组列表、卡片管理页和笔记面板，理解它们分别用于什么场景。  
**完成标准：**你能分清“卡组”“卡片”和“笔记面板”的作用，并知道什么时候进入哪个页面。

卡组列表适合回答“这些卡片来自哪里、按什么集合组织”。如果你导入或导出卡组，也会从这里开始。

![卡组管理页面显示卡组列表，并提供导入卡组和转换 Anki 卡组入口。](/manual/screenshots/zh-cn/review-card-deck-list-main.png)

卡片管理页更适合回答“某一张卡片现在是什么状态”。你可以搜索卡片，查看主动复习和已归档的内容。

![卡片管理页面显示搜索框、主动复习区域和已归档区域。](/manual/screenshots/zh-cn/review-card-management-main.png)

如果你在学习时想知道这张卡片来自哪条笔记，可以打开笔记面板。它适合在“我想回到原始语境再看一眼”的时候使用。

![卡片练习中的笔记面板显示当前卡片关联的笔记和同一笔记下的卡片。](/manual/screenshots/zh-cn/review-card-study-note-panel.png)

一个简单判断是：

- 想看整体数量和状态：去统计页。
- 想按集合整理：去卡组列表。
- 想找某一张卡：去卡片管理。
- 想回到来源语境：在学习页打开笔记面板。

## 常见问题

**为什么卡片学习页只显示一个问题？**  
这是正常的。问题态故意先隐藏答案，让你有机会先从记忆里提取一次。点 **显示答案** 后再对照解释。

**评分会不会影响卡片以后出现的节奏？**  
评分用于记录你这次对卡片的熟悉程度。你不需要为了让记录好看而选择更高评分，真实反馈更有用。

**卡组和卡片有什么区别？**  
卡组是组织方式，卡片是具体要练习的内容。一个卡组可以包含多张卡片。

**为什么有些卡片和任务或笔记有关？**  
Granoflow 的卡片可以来自任务、项目或笔记中的经验。这样做的目的，是把一次工作里的判断留成以后能回看的材料。

**这份手册会继续补全吗？**  
会。当前首版先覆盖卡片学习链路。后续会继续补任务、项目、回顾、数据、同步、桌面能力和本地接口等章节。每次扩展都会先截图、评审，再写入手册。
