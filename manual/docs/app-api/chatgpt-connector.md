---
title: Granoflow ChatGPT Connector
description: "让 ChatGPT 在授权后访问 Granoflow。"
---

Connector 的意义是把浏览器里的 ChatGPT 和你的 Granoflow 数据连起来。它和本机 MCP 不同，因为 ChatGPT 不在你的电脑进程里运行。

## 一个真实场景

如果你想让 ChatGPT 查询任务或帮你整理回顾，先按 Connector 文档完成授权，再用明确问题请求它读取需要的数据。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

Connector 适合对话式查询和整理，不适合绕过确认去做大批量破坏性修改。

## 什么时候用 Connector

| 场景 | 更适合的入口 | 原因 |
| --- | --- | --- |
| 在 ChatGPT 网页里询问任务 | ChatGPT Connector | ChatGPT 不在你的本机进程里 |
| 本机 agent 读取任务 | MCP Server 或本地 HTTP API | 工具和 Granoflow 在同一台机器上 |
| 手机访问桌面端接口 | 局域网连接 | 需要桌面端地址和访问码 |

::::note[先授权，再提问]
Connector 应该在明确授权后使用。提问时尽量说清楚要读取哪类数据，比如今天任务、某个项目或最近回顾。
::::
