description: "选择本地工具、MCP 或 Connector 的连接方式。"

连接 AI 工具前，先问一个简单问题：这个 AI 在你的电脑上运行，还是在网页/云端运行？答案不同，入口也不同。

## 一个真实场景

本机 agent 可以访问本机地址；网页里的 AI 通常不能直接访问 `127.0.0.1`，需要 Connector 或公开中转方式。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

不要把所有连接方式混在一起试。先选运行位置，再看需要的访问码和地址。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
