MCP Server 更适合本机 agent。它把 Granoflow 的能力包装成工具，让 AI 可以在你的授权和本机环境里调用。

## 一个真实场景

如果你在本机使用 Codex、Claude Code 或类似 agent，MCP 比复制粘贴任务列表更稳。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

先让 Granoflow 桌面端和本地接口可用，再配置 MCP Server。MCP 不是云端同步功能。

## 和 Connector 的区别

| 项目 | MCP Server | ChatGPT Connector |
| --- | --- | --- |
| 运行位置 | 本机 AI 工具附近 | ChatGPT/网页环境 |
| 适合任务 | 本机 agent 自动化、读写任务 | 对话式查询和整理 |
| 关键前提 | 桌面端、本地接口、工具配置 | Connector 授权和账号环境 |

MCP 的优势是贴近本机工作流。它也因此更需要你理解本机接口、访问码和工具权限。
