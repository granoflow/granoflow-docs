---
title: 本机地址与浏览器调试
description: "用本机地址检查接口是否可访问。"
---

浏览器调试适合确认接口是否活着。它不能替代完整工具配置，但能帮你判断问题是不是出在连接层。

## 一个真实场景

如果 AI 工具连不上，先在同一台电脑浏览器里访问本机地址；如果浏览器也不通，问题就不在 AI 工具。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

本机地址只代表当前设备。换到手机或网页 AI 时，地址含义会变化。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
