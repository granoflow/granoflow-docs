title: 手机端局域网连接
description: "让同一局域网设备访问桌面端接口。"
---

局域网连接多了一层环境：设备必须在同一网络里，地址要指向桌面端机器，还要有访问码。

## 一个真实场景

如果手机连不上，先确认手机和电脑是否在同一个 Wi-Fi，再看电脑防火墙和访问日志。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

局域网连接只适合受信任网络。公共网络里不要随便打开访问入口。
