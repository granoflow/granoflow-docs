---
title: 官方文档调试
description: "按文档检查接口连接问题。"
---

调试时最怕跳步骤。官方文档的价值是给你一条固定顺序：先看桌面端，再看地址，再看访问码，再看请求内容。

## 一个真实场景

如果你已经换了好几种工具都失败，先回到官方文档里的最小请求，确认接口本身可用。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

最小可复现请求通过后，再回到具体工具配置。这样更容易定位问题。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
