title: 安全访问码
description: "理解访问码为什么存在，以及何时需要填写。"
---

访问码的作用是阻止不相关的本机或局域网请求直接访问 Granoflow。它不是账号密码，但同样需要谨慎对待。

## 一个真实场景

当脚本、AI 工具或局域网设备请求本地接口时，访问码用于证明这次连接是你允许的。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

不要把访问码写进公开仓库、截图或聊天记录。临时调试后，及时检查访问日志。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
