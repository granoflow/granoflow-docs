description: "理解恢复密钥和云端加密数据的关系。"

恢复密钥更像开锁工具，不是普通登录密码。账号能证明你是谁，密钥决定你能否打开某些加密数据。

## 一个真实场景

如果你准备换设备，先确认恢复密钥或旧设备仍可用；等到旧设备已经清掉，再找密钥会困难很多。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

::::caution[不要把密钥当成可随时找回的提示]
如果密钥丢失，某些加密数据可能无法在新设备上打开。先保存好，再继续换设备或重装。
::::
