---
title: 本地优先是什么意思
description: "理解 Granoflow 为什么先把数据放在本地。"
---

本地优先的意思是，日常使用不应该因为网络状态就停下来。你在设备上创建和整理的内容，会先落到本地。

## 一个真实场景

在地铁上整理任务时，即使网络不稳定，你也应该能继续记录；等网络恢复，再处理同步。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

本地优先不等于不用备份。重要数据仍要关注同步状态和本地备份。

任务、项目、回顾和卡片里可能会放进私人计划、客户线索或工作上下文。没有开启同步时，这些内容不会因为安装 MCP Server、使用命令行工具或打开本地接口就自动上传到云端。它们仍然由本机正在运行的 GranoFlow app 管理。

开启同步后，数据会按同步设置进入你的账号环境。这个时候要看的不是 MCP 或 CLI，而是账号、同步状态、恢复密钥和备份说明。换设备、恢复数据或处理加密提示时，先确认账号和同步状态，再继续写入新数据。

::::note[本机接口只是桥]
Local HTTP API、CLI 和 MCP Server 都是连接本机 GranoFlow 的方式。它们不自带另一份任务数据库，也不替代备份、恢复密钥或云同步。
::::

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
