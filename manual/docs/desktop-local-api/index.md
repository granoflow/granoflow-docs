macOS 版本适合长时间工作时使用。它可以在大屏幕上管理任务、项目、回顾和卡片，也可以通过本机能力与其他工具配合。

## 桌面端能力

- 主窗口：用于日常任务、项目、回顾和卡片管理。
- 菜单栏或窗口入口：用于快速回到 App。
- 本地接口：用于让本机工具在授权范围内连接 GranoFlow。
- 命令行或外部工具：用于高级用户把数据或工作流接入自己的环境。

## 使用边界

本地接口和外部工具应该只在你理解用途时开启。不要把访问码、token、私有地址或调试信息写进公开文档、截图或聊天记录。

## 什么时候看这一页

如果你只是普通使用任务和卡片，不需要先配置本地接口。只有当你要连接 Codex、OpenClaw、Hermes、脚本或浏览器调试时，再回到这一页。
