title: CLI 如何工作
description: "理解 CLI、本地 HTTP API 和桌面端之间的关系。"
---

CLI 不是另一套数据系统。它只是通过本机接口和正在运行的 Granoflow 桌面端说话。

## 一个真实场景

当你运行脚本创建任务时，实际数据仍进入 Granoflow；脚本只是换了一种入口。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

如果桌面端没启动，CLI 通常也无法完成需要本地接口的操作。先让应用运行起来。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
