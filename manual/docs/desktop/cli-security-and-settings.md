本地接口的安全重点是范围。它应该服务你这台设备上的工具，而不是默认暴露给所有人。

## 一个真实场景

如果你只在本机用 AI 工具，优先使用本机地址；如果要让手机或局域网设备连接，才考虑局域网地址和访问码。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

::::caution[不要随意公开访问码]
访问码相当于允许工具访问本机 Granoflow 的凭据。只给你信任的本机或局域网工具使用。
::::
