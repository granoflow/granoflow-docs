title: CLI 工作流
description: "把任务查询、创建和更新放进本机自动化。"

CLI 工作流适合重复、明确、低风险的动作。越需要人工判断的事，越应该回到 Granoflow 界面里确认。

## 一个真实场景

比如每天导出今天任务可以脚本化；是否删除一批任务，就应该人工看过再做。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

先自动化读取和创建，再考虑更新；先做可撤回的小动作，再做影响范围大的动作。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
