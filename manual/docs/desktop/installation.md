description: "安装并启动 Granoflow 桌面端。"

桌面端是本地使用、命令行工具和部分本机接口的基础。先把应用正常启动，再谈脚本、连接或高级设置。

## 一个真实场景

如果你只是看手册，可以不用安装；如果你要让本机 AI 或 CLI 读取 Granoflow，就需要桌面端运行。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

安装后先完成一次普通启动，确认能打开主界面，再继续配置本地接口。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
