An account isn't the whole of GranoFlow, but it determines how you restore identity across devices, sync data, and view membership status.

## A Real-World Scenario

If you're using GranoFlow locally on a single computer, you can mostly skip account settings for now. But if you plan to switch devices or use sync, you'll need to check login, recovery, and device joining status.

## Approach the Account Page by Your Question

![Account page](../../screenshots/en/route-account-main.png)

The account page first tells you your current login identity. Whenever sync, subscription, or recovery is involved, the first step is confirming this account is the one you want to use.

![Account recovery page](../../screenshots/en/route-account-recovery-main.png)

The account recovery page is for managing recovery clues when switching devices or losing access. It's not a daily entry point—only focus on it when identity or keys need to be re‑confirmed.

When adding a new device to sync, first confirm the old device and current account status. This handles "join this device to the existing data link," not creating a fresh set of empty data.
