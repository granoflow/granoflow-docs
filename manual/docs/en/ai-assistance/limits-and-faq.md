When AI assistance fails, first determine whether it's a connection issue, a data scope problem, or simply an unsuitable suggestion. Don't use the same fix for different problems.

## A Real Scenario

If AI doesn't respond, check network or settings first; if suggestions are inaccurate, see whether your input is too vague; if changes are excessive, go back to the confirmation step and handle each item individually.

## How to Decide the Next Step

| Situation | What to Check First | Next Step |
| --- | --- | --- |
| Don't know where to start | Current page title and main entry points | Select only one item related to your current goal |
| Action result is incorrect | Status, empty prompts, access history, or sync progress | Return to the previous level and troubleshoot in order |
| Worried about affecting data | Backup, sync, account, or permission info | Stop first, confirm the scope, then continue |

## Limits

AI is good at helping you organize material, but it's not suitable for replacing your own judgment on task priorities and personal boundaries.

## Next Steps

After reading this section, return to the task you are working on and take only one minimal action: record an input, check a status, or open related settings to complete a confirmation.
