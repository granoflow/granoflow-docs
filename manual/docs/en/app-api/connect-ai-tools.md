Before connecting an AI tool, ask a simple question: Is this AI running on your local machine or on the web/cloud? The answer determines the entry point.

## A Real Scenario

A local agent can access local addresses; an AI on the web typically cannot directly access `127.0.0.1` and requires a Connector or a public relay method.

## Boundaries

Don't try all connection methods together. First, choose the runtime location, then check the required access codes and addresses.
