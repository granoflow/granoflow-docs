LAN connection adds an extra layer: devices must be on the same network, the address must point to the desktop machine, and an access code is required.

## A Real Scenario

If your phone can't connect, first check that the phone and computer are on the same Wi-Fi, then check the computer firewall and access logs.

LAN connections are only suitable for trusted networks. Do not casually open the access entry on public networks.
