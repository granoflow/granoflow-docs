The access code prevents unrelated local or LAN requests from reaching Granoflow directly. It is not an account password, but you should treat it just as carefully.

## A Real-World Scenario

When a script, AI tool, or LAN device requests a local interface, the access code proves that you authorized this connection.

## Boundaries

Never write the access code into a public repository, screenshot, or chat log. After temporary debugging, check the access logs promptly.
