The key to new device sync is not which button to click, but first figuring out which device has the latest data and which device is just preparing to join.

## A Real Scenario

If your desktop is the device you've been using most recently, let it finish syncing first, then add the new device. Don't let two devices each create a similar set of data at the same time.
