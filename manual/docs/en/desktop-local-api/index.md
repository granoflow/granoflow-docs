The macOS app is useful for long desk sessions. Command-line access, local access logs, AI assistant settings, and prompt settings let local tools connect to Granoflow when you understand the boundary.

If you only use tasks and cards, you do not need to configure these entry points first. Return here when you connect local scripts, Codex, OpenClaw, Hermes, or another tool.

## Where to start

Start from the sidebar, settings, or the current workflow entry point instead of relying on an old remembered path.

## How to use it

1. Confirm that the current page is the right entry point for the workflow.
2. Do the smallest useful action first, then observe how the page changes.
3. Move durable judgment back into tasks, projects, reflection, or cards.
