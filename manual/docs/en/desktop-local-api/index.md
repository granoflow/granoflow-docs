The macOS app is useful when you spend long periods working at a desk. The main window handles tasks, projects, reflection, and cards. Desktop entry points help you return quickly. Local interfaces let authorized tools connect to Granoflow on your machine.

Only enable local interfaces when you understand why you need them. Do not publish access codes, tokens, private addresses, or debugging details in screenshots or shared text.
