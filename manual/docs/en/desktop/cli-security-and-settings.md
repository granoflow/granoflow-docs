The security focus of local interfaces is scope. They should serve the tools on your device, not be exposed to everyone by default.

## A Real-World Scenario

If you only use AI tools on your local machine, prefer using the local address; if you need to connect from a phone or LAN device, then consider the LAN address and access code.

## Boundaries

::::caution[Do not share access codes carelessly]
An access code is equivalent to credentials that allow tools to access the local GranoFlow. Only give it to trusted local or LAN tools.
::::
