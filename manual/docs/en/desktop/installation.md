The desktop app is the foundation for local use, command line tools, and certain native interfaces. First get the application running properly, then move on to scripts, connections, or advanced settings.

## A Real Scenario

If you're just reading the manual, you don't need to install anything. But if you want your local AI or CLI to access GranoFlow, the desktop app must be running.
