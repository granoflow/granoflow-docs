Offline use covers the ability to record and organize when there’s no network temporarily. Updates keep features and fixes on the current version.

## A Real‑World Scenario

When organizing tasks while traveling, you can record offline first; once back in a stable network environment, check sync and updates.

## How to Decide What’s Next

## Boundaries

During offline periods, don’t treat sync status as a failure. Wait until the network is restored, then observe whether data continues to upload.
