Closing the desktop window does not always mean a full exit. The tray or menu bar status affects local interfaces, notifications, and background capabilities.

## A Real Scenario

If the CLI suddenly cannot connect, first check whether the application is still running, rather than just checking if the main window is open.

| Worried about affecting data | Backup, sync, account, or permissions documentation | Stop first, confirm the scope, then continue |

## Boundaries

Understanding the difference between the window, the tray, and a full exit makes troubleshooting desktop issues much easier.
