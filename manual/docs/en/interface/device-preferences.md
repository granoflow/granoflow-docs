Device preferences answer the question "how does this device feel best to use?" — they are not global account rules. Desktop, phone, and tablet can each have their own habits.

## A Real‑World Scenario

For example, the desktop might prefer landscape, dark mode, and denser lists, while the phone might work better with a simpler entry point. They serve different contexts and don’t need to be identical.

## Boundaries

If a setting only affects the current device, don’t treat it as a sync issue. Adjust it on the device you’re using now, then observe the experience on that device.
