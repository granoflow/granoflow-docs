When several tasks serve the same outcome, a project makes them easier to understand. A domain is a longer-running area you care for: work, study, relationships, body, or rest.

A project organizes a stretch of work. A domain reminds you which larger area that work belongs to. The point is simple: tasks should not remain loose fragments forever.

## Where to start

Start from the sidebar, settings, or the current workflow entry point instead of relying on an old remembered path.

## How to use it

1. Confirm that the current page is the right entry point for the workflow.
2. Do the smallest useful action first, then observe how the page changes.
3. Move durable judgment back into tasks, projects, reflection, or cards.
