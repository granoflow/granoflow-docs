---
title: "Projects and Milestones"
description: "Put longer work back into structure."
docType: "Explanation"
readerGoal: "Know when to turn tasks into projects and milestones."
---

Create a project when several tasks serve the same outcome. A project should make the work easier to understand, not heavier to manage.

Milestones split longer work into observable stages. They answer “what should this phase reach?” while tasks answer “what do I do next?”

Start simple: create the project, add the clearest next task, then add milestones when the work needs more structure.
