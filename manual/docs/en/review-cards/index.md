Review cards turn reusable experience into prompts you can retrieve later. The point is not to memorize every word; it is to make a useful judgment easier to recall when similar work returns.

This page uses the fixed seed card “What is a domain?” Every locale uses the localized version of the same card, so the screenshots and copy stay aligned.

## Where to start

Start from card practice. Read the question before revealing the answer.

## How to use it

1. Confirm that the current page is the right entry point for the workflow.
2. Do the smallest useful action first, then observe how the page changes.
3. Move durable judgment back into tasks, projects, reflection, or cards.

One practice round works best when you retrieve first, reveal the answer, then rate how familiar it felt.
