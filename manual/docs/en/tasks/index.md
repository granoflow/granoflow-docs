A task is the smallest action unit in Granoflow. It can start as an inbox item, a clear next step, or a piece of work linked to a project.

## Basic Flow

1. Capture the thing before it disappears.
2. Decide whether it belongs to a project, domain, or milestone.
3. Break it down if it is too large to start.
4. Complete, archive, or adjust it after progress.

A useful task usually says what to do, what completion looks like, and what larger direction it belongs to. If you do not know yet, capture it first and clarify it later.
