A project is not a big task—it’s work that requires multiple steps to move forward. Milestones help you see intermediate results.

## A Real-World Scenario

Writing a thesis, preparing a portfolio, or developing a course project all fit well into a project. “Send an email today” is usually just a task.

## How to Decide the Next Step

| What you’re facing | Check first | Next step |
| --- | --- | --- |
| Not sure where to start | Current page title and main entry | Choose only the item that relates to your current goal |
| Result is wrong after an action | Status, empty prompt, access history, or sync progress | Go back one level and troubleshoot in order |
| Worried about affecting data | Backup, sync, account, or permissions docs | Stop first, confirm the scope, then proceed |

## Boundaries

When something needs to be worked on over several consecutive weeks, don’t rely solely on a task list. Give it a project container.

## Next Step

After reading this section, go back to the task you’re working on and choose just one smallest action to continue: record an input, check a status, or open the relevant settings to confirm once.
