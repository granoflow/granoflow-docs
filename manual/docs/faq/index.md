## 一个真实场景

如果你只是想知道“为什么手机上看不到桌面端的新任务”，先看同步和账号；如果想系统理解工作流，回到开始使用和任务章节。

## 常见问题通常从这三处开始

![设置总览](../../screenshots/zh-cn/route-settings-main.png)

设置总览适合先找入口。账号、数据、AI、通知和桌面连接问题，都可以从这里分流。

![数据管理](../../screenshots/zh-cn/route-data-management-settings-data-management-main.png)

数据管理适合处理备份、导入、附件和卡组。只要问题涉及迁移、恢复或空间占用，就先看这里。

![同步进度](../../screenshots/zh-cn/route-sync-progress-sync-main.png)

同步进度适合判断多设备数据是否还在路上。新设备看不到内容时，先别急着重建数据，先看同步是否完成。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

常见问题的答案通常指向一个更具体页面。找到方向后，再进入对应章节处理。

## 常见判断

| 问题 | 先看哪里 | 常见下一步 |
| --- | --- | --- |
| 新设备看不到数据 | 账号与同步 | 确认账号一致，再看同步状态 |
| 会员没有出现 | 订阅与恢复购买 | 确认购买平台和当前账号 |
| AI 建议不准确 | AI 辅助设置 | 缩小输入范围，确认后再写入 |
| CLI 连不上 | 桌面端和访问日志 | 先验证本机接口可用 |
| 附件占空间 | 数据管理 | 清理前确认是否还需要打开 |

## 任务管理常见问题

| 问题 | 简短答案 |
| --- | --- |
| 收集箱是不是“没有项目”的任务列表？ | 不是。收集箱主要看任务有没有安排日期。一个没有日期的项目任务，也可能留在收集箱里。 |
| 每条任务都要放进项目吗？ | 不需要。几分钟能完成、只提醒自己一次的小事，直接作为任务就够了。会持续推进、产生多条任务的目标，再建项目。 |
| 项目完成会自动完成里面所有任务吗？ | 不会。项目、里程碑和任务各自有状态。更稳的做法是先处理任务和里程碑，再完成或归档项目。 |
| 完成和归档有什么区别？ | 完成表示事情做完，会进入完成记录和回顾；归档表示暂时收起，不等于完成。 |
| 任务开始/完成时间是不是专注时间？ | 不是同一个概念。任务时间用于记录这件事的历史时间块；心流或专注时间是你在回顾里确认的日级记录。 |
| AI 回顾会直接改我的任务吗？ | 不会直接改。AI 生成内容需要你确认后才会写入；你也可以只把它当作整理素材。 |
| MCP Server 会把任务存到云端吗？ | 不会。MCP Server 只是本机 AI 工具连接本机 GranoFlow 的桥；数据源仍是正在运行的 GranoFlow app。 |
| 可以从其他待办工具一键导入所有历史吗？ | 目前不要按这个假设规划。更建议小批量整理仍然有用的任务，把历史完成记录只补到真正会影响回顾的部分。 |

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
