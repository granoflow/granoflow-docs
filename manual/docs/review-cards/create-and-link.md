---
title: 创建与关联卡片
description: "从任务、回顾或已有经验里创建卡片，并把卡片关联回具体任务。"
---

创建卡片时，先别问“我能不能把这段话存起来”。更好的问题是：**以后遇到类似任务时，我想让自己先想起哪一句？**

Granoflow 允许你单独新建卡片，也可以从任务详情里添加卡片。两种入口的目的不同：单独新建适合整理已经想清楚的经验；从任务里添加适合把刚完成、刚回顾出来的判断绑回原来的工作现场。

## 先写能被练习的问题

![新建卡片页](../../screenshots/zh-cn/route-review-card-new-review-cards-new-main.png)

新建卡片页的重点不是把内容写长，而是把问题写清楚。一个好问题应该让你在练习时能先停一下，自己组织答案。

| 不太适合 | 更适合 |
| --- | --- |
| “项目管理很重要” | “项目延期时，先检查哪三件事？” |
| “收集箱要清空” | “什么情况下任务应该离开收集箱？” |
| “回顾有帮助” | “完成任务后，哪类经验值得做成卡片？” |

答案也不需要像教材。写成你以后能看懂的一段话就好，最好带一个真实例子。比如“如果任务已经有项目、日期或下一步，就不要继续放在收集箱里；收集箱只放还没整理清楚的输入。”

## 从任务里创建卡片

![任务新增卡片页](../../screenshots/zh-cn/route-task-review-card-add-tasks-taskid-cards-add-main.png)

任务详情里的“任务卡片”区域适合处理刚从行动里冒出来的经验。图中右侧是任务详情，底部有“添加卡片”入口。这个入口的好处是：卡片一开始就知道自己来自哪件事，不会变成孤零零的一条笔记。

可以按这个顺序做：

1. 打开相关任务。
2. 先看任务标题、说明和节点，确认这次真正学到的是什么。
3. 在“任务卡片”区域添加卡片。
4. 用一句问题抓住下次要提醒自己的点。
5. 用答案写清楚当时的判断和例子。

不要把任务说明复制进卡片。任务说明回答“这件事是什么”，卡片回答“下次遇到类似情况，我要怎么判断”。

## 关联已有卡片

![卡片详情页](../../screenshots/zh-cn/route-review-card-temp-import-card-review-cards-temp-imports-tempdeckid-main.png)

卡片详情页会显示卡片题目、来源、学习状态和关联任务。图里的卡片“什么是领域？”已经关联到一个任务。这个关联很重要：它让卡片不只是知识条目，而是能回到具体行动的提醒。

如果你已经有一张合适的卡片，就不要再新建一张近似卡片。先打开原卡片，确认它是否能覆盖这次任务；如果能，关联即可。如果它只差一点点，可以编辑答案，让它更像一条可复用经验。

## 什么时候不要做卡片

有些内容留在任务或回顾里更好：

| 情况 | 放在哪里更好 | 为什么 |
| --- | --- | --- |
| 一次性的安排 | 任务 | 做完就结束，不需要反复练 |
| 当天的情绪记录 | 日记或回顾 | 不适合变成练习题 |
| 大段过程复盘 | 回顾 | 卡片太长会降低练习质量 |
| 账号、链接、隐私信息 | 不建议放卡片 | 卡片会被反复展示和导出 |
| 一句可复用判断 | 卡片 | 下次能直接帮你做选择 |

## 写卡片时的小标准

一张卡片写完后，可以用下面四个问题检查：

| 检查问题 | 通过标准 |
| --- | --- |
| 问题是否具体 | 看到问题后，知道要回忆哪类判断 |
| 答案是否能操作 | 不只是道理，而是能指导下一步 |
| 例子是否来自真实任务 | 不是空泛建议，而是你确实遇到过 |
| 是否值得再见一次 | 下次练到它时，你不会觉得浪费时间 |

## 下一步

创建几张卡片后，不要急着继续堆数量。去[练习、掌握与内化](./study-and-internalize/)做一轮短练习，看看这些卡片在题面状态下是否真的能让你想起答案。
