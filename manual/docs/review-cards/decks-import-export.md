卡组用来把一批相关卡片放在一起。它适合整理主题，比如“任务收集与收集箱工作流研究”“认识 Granoflow”。但它不应该变成另一个文件柜：卡组越清楚，练习时越容易知道这些卡片为什么放在一起。

## 卡组列表怎么看

![卡组管理](../../screenshots/zh-cn/review-card-deck-list-main.png)

卡组管理页会显示每个卡组的名称、来源和学习状态。图里有两个卡组：一个来自任务研究，一个用于认识 Granoflow。每个卡组下面会显示活跃卡片数、已归档数、未学习、学习中、已掌握和已内化。

这里最值得看的不是卡组有多少，而是它们是否仍然对应真实使用场景。如果一个卡组很久没有练，也没有关联任务，它可能只是“资料堆”；如果它能帮你处理一类常见任务，就值得保留。

## 导入前先筛一遍

![待筛选卡组入口](../../screenshots/zh-cn/route-review-card-deck-list-review-cards-decks-main.png)

页面顶部有“导入卡组”“转换 Anki 卡组”“待筛选卡组”。导入不是把外部内容直接塞进练习队列，而是先放到可检查的位置。这样你可以先删掉不适合自己的卡片，再决定哪些进入正式卡组。

这个步骤很像搬家前整理箱子：不是所有东西都应该进新家。尤其是别人写的卡片，语言、例子、问题方式都可能不适合你。

## 三种文件不要混用

| 类型 | 用途 | 适合做什么 | 不适合做什么 |
| --- | --- | --- | --- |
| `.deck.grano` | 卡组包 | 分享或迁移一组卡片 | 当成完整备份 |
| `.flow.grano` | Granoflow 备份 | 恢复本地数据 | 当成公开分享包 |
| Anki `.apkg` | Anki 卡组 | 通过离线工具转换成 Granoflow 可读内容 | 直接替代 Granoflow 卡组 |

`.deck.grano` 关注卡片和卡组，不等于你的全部 Granoflow 数据。需要备份时，请使用备份相关功能；需要分享一组卡片时，再使用卡组导出。

::::caution[导出前先检查内容]
卡片可能包含任务名称、项目背景、个人判断或工作细节。导出卡组前，先确认里面没有不适合分享的信息。
::::

## Anki 转换适合什么情况

如果你已经有 Anki 卡组，可以用“转换 Anki 卡组”把它变成 Granoflow 能继续筛选的材料。这个入口适合迁移旧素材，不适合不加选择地导入大量卡片。

转换后仍然要检查三件事：

1. 问题是否适合 Granoflow 的使用场景。
2. 答案是否能带回任务、项目或回顾。
3. 是否有图片、音频、链接等内容在当前环境里无法正常使用。

如果一张 Anki 卡片只是背单词或考试知识，它未必适合放进 Granoflow；如果它能帮你形成工作判断、复盘习惯或行动提醒，就可以留下。

## 什么时候建立新卡组

| 情况 | 建议 |
| --- | --- |
| 只有一两张零散卡片 | 暂时不建新卡组 |
| 围绕同一类任务有五六张以上卡片 | 可以建卡组 |
| 要把一批外部卡片先检查后再使用 | 用导入和待筛选 |
| 想备份全部数据 | 不用卡组导出，去看备份功能 |
| 想分享一套经过整理的经验 | 导出 `.deck.grano` |

卡组的名字也要具体。比如“项目管理”太大，“项目延期时的下一步判断”更容易让你知道什么时候打开它。

## 下一步

整理好卡组后，回到[练习、掌握与内化](./study-and-internalize/)做一轮短练习。真正的目标不是拥有整齐的卡组，而是让其中几张卡片在下一次行动前派上用场。
