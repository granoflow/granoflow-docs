卡片练习不是为了证明你记性好。它的作用更朴素：在真正做事前，让那些已经总结过的经验重新浮上来。

如果你把卡片当成“每天必须完成的打卡”，很容易变成负担。更好的用法是：每天做一小轮，把最容易忘、最可能帮到今天的提醒捡起来。

## 先自己想，再看答案

![卡片练习题面](../../screenshots/zh-cn/review-card-study-domain-garden-question.png)

题面只显示问题，是为了留出一个短暂停顿。看到“什么是领域？”时，先不要急着点答案。你可以在心里用自己的话答一遍：领域像人生里的几个花园，任务要放回更大的生活版图里看。

这个停顿很重要。只阅读答案会让人产生“我懂了”的感觉，但下次做任务时未必想得起来。先回忆，再校正，效果会扎实很多。

## 根据真实感觉选择反馈

![卡片练习背面](../../screenshots/zh-cn/review-card-study-domain-garden.png)

显示答案后，底部会出现四个反馈按钮。它们不是情绪评价，而是给下一次练习排队用的信号。

| 按钮 | 什么时候点 | 它表达的意思 |
| --- | --- | --- |
| 遗忘 | 完全想不起来，或答案方向错了 | 这张卡需要更快再出现 |
| 勉强 | 想起一点，但需要答案帮忙 | 还不稳定，继续练 |
| 记得 | 基本答对，只是表达不够顺 | 可以按正常节奏继续 |
| 轻松 | 不用费力就能想起，并且知道怎么用 | 可以隔久一点再出现 |

不要为了让统计好看而点“轻松”。如果一张卡片在真实任务里还经常用不上，就诚实点“勉强”或“记得”。Granoflow 不是在考你，它只是在帮你安排下一次提醒。

## 掌握和内化有什么区别

![卡片统计](../../screenshots/zh-cn/review-card-statistics-main.png)

统计页里的“已掌握”和“已内化”不是奖章。你可以这样理解：

| 状态 | 更像什么 | 你可以怎么用 |
| --- | --- | --- |
| 未学习 | 刚放进抽屉的提醒 | 先挑今天相关的练 |
| 学习中 | 还需要多见几次的提醒 | 不急着判断成败 |
| 已掌握 | 看到问题能比较稳定地答出来 | 继续观察真实任务中是否用上 |
| 已内化 | 不看卡片也常常能自然想到 | 可以把精力留给更新的经验 |

一张卡片真正有价值，不是因为它变成“已内化”，而是因为它改变了你下一次处理任务的方式。比如你开始任务前会自然问：“这件事属于哪个领域？是不是该放进项目里？”这就说明它已经从卡片回到了行动。

## 什么时候练习

你不需要等到状态很好才练习。最适合的时间通常很短：

| 场景 | 练习方式 |
| --- | --- |
| 开始工作前 | 练 3 到 5 张，帮自己进入状态 |
| 完成回顾后 | 练和刚才经验相关的卡片 |
| 项目推进卡住时 | 搜索相关卡片，找以前的判断 |
| 一天结束前 | 做一小轮，把今天可能用到的提醒收尾 |

如果练习过程中发现一张卡片总是答不出来，不一定是你没记住，也可能是卡片写得太抽象。回到卡片详情，把问题改得更具体，或者在答案里加一个例子。

## 不要把练习变成压力源

卡片学习应该帮你减轻反复踩坑的成本，而不是多制造一个待办清单。今天只练了两张也没关系；关键是这两张有没有帮你想起一个具体做法。

一个实用做法是：练习结束后，挑一张最有用的卡片，马上问自己一句：**今天哪件事可以用上它？**如果能回答出来，这次练习就已经落到地上了。
