完成一项任务并不表示它的价值已经结束。很多时候，真正值得留下的是你在过程中做出的判断：哪里卡住了、什么方法有效、下次可以更早注意什么。

## 怎么回顾

1. 从刚完成或刚推进的任务开始。
2. 写下事实：做了什么、结果是什么。
3. 写下判断：为什么这样做，哪里值得保留。
4. 如果有明确下一步，把它转回任务或项目。
5. 如果某个判断以后会反复用到，把它做成记忆卡片。

## 好的回顾长什么样

好的回顾不需要长。它应该足够具体，让未来的你能看懂当时的处境。与其写“今天效率不错”，不如写“先列验收项再改文案，减少了返工”。

## 边界

回顾不是评价自己好坏。它只是把事实、判断和下一步记录下来。避免把回顾写成诊断、承诺或压力来源。
