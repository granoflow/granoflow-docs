---
title: 创建与编辑任务
description: "创建与编辑任务：先写标题，再按需要补日期、项目、标签、步骤和回顾。"
---

创建任务时，不需要一次填完所有字段。最小动作只有一个：写标题并保存。其他内容可以等任务真的要推进时再补。

更稳的理解是：标题让事情被记住，日期让它进入某一天，项目说明它属于哪个目标，标签帮助筛选，步骤负责拆小，回顾记录做完后的经验。

## 从哪里创建任务

| 入口 | 适合什么时候用 | 保存后的特点 |
| --- | --- | --- |
| 底部 **+** 按钮 | 想马上记下一件事 | 没有日期时进入收集箱 |
| 收集箱里的输入区 | 正在整理临时想法 | 适合连续补充待整理事项 |
| 任务列表的时间分区 | 已经知道大概哪天做 | 会带上对应日期 |
| 项目或里程碑里 | 已经知道目标归属 | 会带上项目或阶段 |
| 任务详情的节点区 | 想拆小当前任务 | 成为这条任务的一部分 |

如果你只是怕忘记，直接用 **+** 就好。等之后整理时，再决定它属于哪一天、哪个项目。

## 字段分别负责什么

| 字段 | 是否必填 | 作用 |
| --- | --- | --- |
| 标题 | 必填 | 写清楚要做什么 |
| 描述 | 可选 | 放背景、链接、草稿或说明 |
| 截止日期 | 可选 | 决定任务出现在哪一天 |
| 提醒 | 可选 | 到指定时间通知；不能设在过去 |
| 项目 | 可选 | 说明任务属于哪个目标 |
| 里程碑 | 可选 | 说明任务属于项目里的哪个阶段 |
| 标签 | 可选 | 用来筛选同类任务 |
| 节点 | 可选 | 把大任务拆成小步骤 |
| 任务回顾 | 完成或归档后使用 | 记录实际情况和下次可复用的判断 |
| 任务卡片 | 项目任务中使用 | 把经验保存成以后可练习的卡片 |

::::tip[标题先写成动作]
“论文”太大，“写论文第三章第一段”更容易开始。标题不一定要长，但最好能让你知道下一步手要放在哪里。
::::

## 保存后任务去哪了

任务保存后出现在哪里，取决于你填了哪些字段。

| 任务信息 | 会出现在哪里 |
| --- | --- |
| 没有日期 | 收集箱 |
| 有日期 | 对应日期的任务列表 |
| 有项目或里程碑 | 对应项目或阶段；如果没日期，也仍在收集箱 |
| 在项目里创建 | 默认归属到该项目；是否进任务列表仍看日期 |

修改日期、项目或里程碑，不会复制任务。它只是改变同一条任务的视图位置和归属。

## 编辑已有任务

点击任务就能打开详情。任务详情不是只用来改标题，它负责集中查看和补充这件事的上下文。

你通常会在详情里做这些事：

- 改标题，让下一步更清楚
- 补日期、提醒、标签、项目或里程碑
- 在描述里放背景、链接或草稿
- 用节点拆成几个小动作
- 查看图片、附件和相关历史参考

任务详情不放“开始专注”和“完成任务”按钮。做完以后，回到任务列表勾选这条任务的核对框；专注入口以应用当前提供的位置为准。

::::note[提醒时间的边界]
提醒不能设置在已经过去的时间。如果你选了过去时间，系统会提示你重新选择。
::::

## 标签模板会不会覆盖内容

如果你选择的自定义标签带有模板，并且这条任务还没有描述和节点，GranoFlow 会把模板内容添加到任务描述和根节点里。

如果任务已经有描述或节点，模板会跳过，避免覆盖你已经写好的内容。同一个标签模板对同一条任务只会自动添加一次；如果模板添加失败，标签选择仍会保留，你可以稍后手动补充。
