title: 收集箱
description: "收集箱：先把还没整理的任务放下来，之后再决定日期、项目或删除。"
---

收集箱不是最终任务列表，也不是项目管理区。它更像一块临时桌面：你想到一件事，先放下来，晚一点再决定它是否要安排日期、放进项目，或者直接删掉。

用好收集箱的关键，是把“记录”和“整理”分开。想到事情时先记录，真正整理时再判断。

## 收集箱里通常是什么

![收集箱](../../screenshots/zh-cn/route-inbox-main.png)

收集箱显示的是没有日期、并且仍然是待办或进行中的任务。图里的重点是“未安排”：这些任务还没有进入某一天的计划，所以先停在这里等你处理。

如果一条任务已经有日期，它就会去对应日期的任务列表；如果它完成、归档或删除，也会从收集箱消失。

## 怎么把任务放进收集箱

点底部 **+**，写下任务标题，然后保存。只要没有选择日期，它就会进入收集箱。

刚记录时可以写得很普通：

- 明天联系客户
- 整理课程笔记
- 买牙线
- 周末约朋友吃饭

后面整理时，再把它改成更具体的动作、补日期、放进项目或加标签。

## 为什么有些任务不在收集箱

| 你做了什么 | 任务会去哪 |
| --- | --- |
| 没选日期，直接保存 | 留在收集箱 |
| 选了日期 | 出现在那一天的任务列表 |
| 加入项目，但没选日期 | 仍在收集箱，同时归属到项目 |
| 在项目里创建，但没选日期 | 仍在收集箱，同时归属到项目 |
| 完成、归档或删除 | 离开收集箱，进入对应状态 |

这里最容易误解的是项目归属。把任务加入项目，不会单独让它离开收集箱；日期才决定它是否进入某一天的任务列表。

::::note[收集箱不是“没有项目”的列表]
收集箱看的是有没有日期，不是有没有项目。一个没有日期的项目任务，仍然可以出现在收集箱里。
::::

## 怎么整理收集箱

整理时不用追求清空。按下面几个问题处理就够了：

| 问题 | 如果答案是“是” | 下一步 |
| --- | --- | --- |
| 需要某天完成吗 | 是 | 加日期 |
| 属于某个长期目标吗 | 是 | 放进项目或里程碑 |
| 太大、不知道怎么做吗 | 是 | 拆成步骤 |
| 已经不值得做吗 | 是 | 删除或归档 |
| 很快能做完吗 | 是 | 直接做掉 |

::::tip[一个小习惯]
每天开始前看一眼收集箱，把真正重要的任务安排到今天或明天。剩下暂时不急的可以继续留着，不必强迫自己每天清空。
::::

## 下一步

收集箱里的内容变清楚后，就可以进入“创建与编辑任务”，给任务补日期、项目、标签或步骤。
