任务是 GranoFlow 里最小的行动单位。它适合承接“现在想到但还没安排”的事情，也适合承接已经明确的下一步。

## 基本流程

1. 先把事情放进收集箱或任务列表。
2. 看清这件事是否属于某个项目、领域或里程碑。
3. 如果它太大，拆成能开始的一步。
4. 推进之后，根据实际结果完成、归档或继续调整。

每一步都应该让任务更接近“可以行动”。如果任务标题只是一个模糊主题，例如“论文”或“产品”，你可以把它改成“整理本周实验结果”或“检查下载页文案”。

## 判断原则

一个好任务通常回答三个问题：做什么、做到哪里算完成、它属于哪个更大的方向。暂时不知道也没关系，可以先收进来，再在整理时补齐。

## 边界

任务不是长期目标本身。长期目标应该进入项目、里程碑或领域；任务负责承接下一步行动。
