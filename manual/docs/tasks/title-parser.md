---

有时你只是想快速记下一件事，不想打开一堆字段。自然语言输入就是为这种场景准备的：你可以在标题里顺手写日期、标签、项目或提醒，GranoFlow 识别后会给出候选，等你确认后再写入对应字段。

它不是让你用一句话替代所有编辑。更准确地说，它是创建任务时的快捷入口。

## 一个例子

```text
整理报告 明天 #工作 @论文初稿 ~下午3点
```

这句话里同时包含了任务标题、日期、标签、项目或里程碑，以及提醒时间。GranoFlow 会把这些内容识别成候选项；你确认后，它们才会进入对应字段。

## 常用写法

| 你输入的内容 | 候选含义 |
| --- | --- |
| `#工作` | 添加“工作”标签 |
| `@论文初稿` | 关联项目或里程碑 |
| `明天`、`下周五`、`3月5日` | 设置截止日期 |
| `~下午3点`、`~明早9点` | 设置提醒时间 |

确认方式通常是点击候选，或按 **Enter** / **Tab** 确认当前候选。按 **Escape** 关闭候选后，未确认的文字会继续留在标题里。

::::caution[确认前不会写入]
识别到的内容不会自动变成标签、日期、项目、里程碑或提醒。你必须明确确认，才会写入对应字段。没有确认的部分会继续作为标题文字保留。
::::

## 为什么要确认

确认步骤看起来多一步，但它能避免误写。比如“下周五讨论设计”可能只是标题内容，也可能是日期；`@官网改版` 可能指项目，也可能只是你想写进标题的文字。

GranoFlow 先给候选，再等你确认，就是为了让最终字段由你决定。

## 常见限制

| 情况 | 更稳的做法 |
| --- | --- |
| `#`、`@`、`~` 粘在奇怪位置 | 放在清楚的词前，比如 `#工作` |
| 想设置日期 | 直接写 `明天`、`下周五`，不要用 `@` |
| 复杂句子识别不准 | 手动打开字段修改 |
| 候选不是你要的 | 不确认，继续把它当标题文字 |

自然语言输入只是省步骤，不是必须使用。识别结果不对时，直接手动设置字段就好。
