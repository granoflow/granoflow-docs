行动系统越常用，数据越值得保护。任务、项目、回顾和卡片都承载了你的工作线索。

## 一个真实场景

换电脑前，先看数据管理、同步进度和新设备加入；不要把迁移当成普通登录。

## 换设备前先看这三处

![数据管理](../../screenshots/zh-cn/route-data-management-settings-data-management-main.png)

数据管理适合在迁移、备份或清理前打开。它回答的是“我能不能带走或恢复这份数据”。

![同步进度](../../screenshots/zh-cn/route-sync-progress-sync-main.png)

同步进度告诉你当前数据是否还在传输。换设备前，如果这里还没有完成，先等它结束。

新设备加入同步是最后一步。只有当旧设备和账号状态都确认后，再让新设备进入同一条数据链路。

## 怎么判断下一步

| 你遇到的情况 | 先看什么 | 下一步 |
| --- | --- | --- |
| 不知道该从哪里开始 | 当前页面标题和主要入口 | 只选择和当前目标有关的一项 |
| 操作后结果不对 | 状态、空提示、访问记录或同步进度 | 回到上一层，按顺序排查 |
| 担心影响数据 | 备份、同步、账号或权限说明 | 先停下，确认范围后再继续 |

## 边界

先保护数据，再追求顺手。这个顺序在换设备时尤其重要。

## 下一步

读完这一节后，回到你正在处理的任务，只选一个最小动作继续：记录一条输入、检查一个状态、或打开相关设置完成一次确认。
