---
title: Granoflow ChatGPT Connector
description: "讓 ChatGPT 在授權後訪問 Granoflow。"
---

Connector 的意義是把瀏覽器裡的 ChatGPT 和你的 Granoflow 數據連起來。它和本機 MCP 不同，因為 ChatGPT 不在你的電腦進程裡運行。

## 一個真實場景

如果你想讓 ChatGPT 查詢任務或幫你整理回顧，先按 Connector 文檔完成授權，再用明確問題請求它讀取需要的數據。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 當前頁面標題和主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、訪問記錄或同步進度 | 回到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

Connector 適合對話式查詢和整理，不適合繞過確認去做大批量破壞性修改。

## 什麼時候用 Connector

| 場景 | 更適合的入口 | 原因 |
| --- | --- | --- |
| 在 ChatGPT 網頁裡詢問任務 | ChatGPT Connector | ChatGPT 不在你的本機進程裡 |
| 本機 agent 讀取任務 | MCP Server 或本地 HTTP API | 工具和 Granoflow 在同一台機器上 |
| 手機訪問桌面端接口 | 局域網連接 | 需要桌面端地址和訪問碼 |

::::note[先授權，再提問]
Connector 應該在明確授權後使用。提問時盡量說清楚要讀取哪類數據，比如今天任務、某個項目或最近回顧。
::::

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一條輸入、檢查一個狀態、或打開相關設置完成一次確認。
