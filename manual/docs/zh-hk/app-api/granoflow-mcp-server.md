---
title: Granoflow MCP Server
description: "為支援 MCP 的本機 AI 工具提供 Granoflow 功能。"
---

MCP Server 更適合本機 agent。佢將 Granoflow 的能力包裝成工具，令 AI 可以喺你的授權同本機環境入面調用。

## 一個真實場景

如果你喺本機使用 Codex、Claude Code 或類似 agent，MCP 比複製貼上任務列表更穩定。

## 點樣判斷下一步

| 你遇到的情況 | 先睇咩 | 下一步 |
| --- | --- | --- |
| 不知由邊度開始 | 當前頁面標題同主要入口 | 只選擇同當前目標有關的一項 |
| 操作後結果不啱 | 狀態、空提示、訪問記錄或同步進度 | 返回上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停低，確認範圍後再繼續 |

## 邊界

先確保 Granoflow 桌面端同本地接口可用，再配置 MCP Server。MCP 並非雲端同步功能。

## 同 Connector 的分別

| 項目 | MCP Server | ChatGPT Connector |
| --- | --- | --- |
| 運行位置 | 本機 AI 工具附近 | ChatGPT/網頁環境 |
| 適合任務 | 本機 agent 自動化、讀寫任務 | 對話式查詢同整理 |
| 關鍵前提 | 桌面端、本地接口、工具配置 | Connector 授權同帳號環境 |

MCP 的優勢係貼近本機工作流程。正因如此，你需要更了解本機接口、存取碼同工具權限。

## 下一步
