---
title: 官方檔案除錯
description: "按照檔案檢查接口連接問題。"
---

除錯時最怕跳步驟。官方檔案的價值係畀你一條固定順序：先睇桌面端，再睇地址，再睇訪問碼，再睇請求內容。

## 一個真實場景

如果你已經換咗好幾種工具都失敗，先返到官方檔案入面的最小請求，確認接口本身可用。

## 點樣判斷下一步

| 你遇到的情況 | 先睇乜 | 下一步 |
| --- | --- | --- |
| 不知應該從邊度開始 | 當前頁面標題同主要入口 | 只選擇同當前目標有關的一項 |
| 操作後結果不啱 | 狀態、空白提示、訪問記錄或同步進度 | 返到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停低，確認範圍後再繼續 |

## 邊界條件

最小可重現請求通過後，再返到具體工具配置。咁樣更容易定位問題。

## 下一步

讀完呢一節之後，返去你正在處理的任務，只選一個最小動作繼續：記錄一條輸入、檢查一個狀態、或打開相關設置完成一次確認。
