---
title: 安全存取碼
description: "了解存取碼為何存在，以及何時需要填寫。"
---

存取碼的作用是阻止不相關的本機或區域網絡要求直接存取 Granoflow。它並非帳號密碼，但同樣需要謹慎處理。

## 一個真實場景

當腳本、AI 工具或區域網絡設備要求本地介面時，存取碼用於證明這次連線是你允許的。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道從哪裡開始 | 當前頁面標題和主要入口 | 只選擇與當前目標有關的一項 |
| 操作後結果不正確 | 狀態、空提示、存取記錄或同步進度 | 回到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

不要把存取碼寫入公開倉庫、截圖或聊天記錄。臨時除錯後，及時檢查存取日誌。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一項輸入、檢查一個狀態、或開啟相關設定完成一次確認。
