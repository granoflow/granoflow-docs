macOS 版本適合長時間桌面工作。命令行、本地訪問記錄、AI 助手和 Prompt 設置，讓本機工具可以在你理解邊界的前提下連接 GranoFlow。

如果你只是普通使用任務和卡片，不需要先配置這些入口。只有當你要連接本機腳本、Codex、OpenClaw、Hermes 或其他工具時，再回來讀這一頁。

## 從哪裡開始

先從側邊欄、設置頁或目前工作流入口進入，不要直接依賴記憶中的舊路徑。

## 怎樣使用

1. 確認目前頁面是不是你要處理的工作流入口。
2. 先完成最小動作，再觀察頁面狀態變化。
3. 把需要長期保存的判斷寫回任務、項目、回顧或卡片。

## 邊界

不要把截圖當成功能承諾。截圖只證明目前 macOS、深色、橫屏、測試 seed 下的可見狀態。賬號、訂閱、同步、AI 或外部工具相關頁面，仍要結合你的權限和本機狀態判斷。
