指令列參考適合已經知道自己要查甚麼的人。先確認桌面端正在執行，再複製指令。

## 一個真實場景

如果指令冇返預期結果，先睇存取日誌同本地介面狀態，不好急住改腳本。

## 先確認介面，再睇指令

![指令列工具設定](../../screenshots/zh-hk/route-command-line-tool-settings-command-line-tool-main.png)

指令列工具設定頁話畀你知本機介面係咪可用、地址係乜、存取碼喺邊。指令行不通的時候，先睇呢度，而不係改腳本。

![存取日誌](../../screenshots/zh-hk/route-local-http-api-access-log-settings-command-line-tool-access-log-main.png)

存取日誌可以幫你判斷請求有冇到達 Granoflow。如果日誌完全冇記錄，問題通常喺地址、埠口、網絡或者工具設定；如果有記錄但失敗，就再睇權限同參數。

## 點判斷下一步

| 你遇到的情況 | 先睇甚麼 | 下一步 |
| --- | --- | --- |
| 不知從邊度開始 | 當前頁面標題同主要入口 | 只選擇同當前目標有關的一項 |
| 操作後結果不啱 | 狀態、空提示、存取記錄或者同步進度 | 返到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或者權限說明 | 先停低，確認範圍之後再繼續 |

## 邊界

指令可以行到的前提係本機服務可用、存取碼正確、請求地址指向當前裝置。

## 使用前提

```bash
granoflow --help
```

如果指令不可用，先返到桌面端安裝同指令列工具設定。指令列參考頁只負責查用法，不負責代替安裝同授權。

| 問題 | 先檢查 |
| --- | --- |
| 指令不存在 | CLI 係咪安裝咗到 PATH |
| 連線失敗 | 桌面端係咪執行緊，本地介面係咪開啟咗 |
| 返未授權 | 存取碼係咪正確 |
| 數據為空 | 當前帳號同本地數據係咪符合預期 |

## 下一步

睇完呢一節之後，返去你正在處理的任務，只選一個最小動作繼續：記錄一項輸入、檢查一個狀態、或者打開相關設定完成一次確認。
