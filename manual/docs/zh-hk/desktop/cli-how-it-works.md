title: CLI 如何運作
description: "理解 CLI、本地 HTTP API 與桌面端之間的關係。"
---

CLI 並非另一套數據系統。它只是透過本機介面與正在運行的 Granoflow 桌面端溝通。

## 一個真實場景

當你執行腳本建立任務時，實際數據仍然進入 Granoflow；腳本只是換了一種輸入方式。

## 如何判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 當前頁面標題及主要入口 | 只選擇與當前目標相關的一項 |
| 操作後的結果不正確 | 狀態、空提示、存取記錄或同步進度 | 回到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

如果桌面端沒有啟動，CLI 通常也無法完成需要本機介面的操作。請先讓應用程式運行起來。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一筆輸入、檢查一個狀態，或開啟相關設定完成一次確認。
