---
title: JSON 與腳本
description: "用結構化輸出連接自動化腳本。"
---

JSON 輸出適合腳本讀取，一般文字輸出適合人看。寫自動化時，盡量讓腳本讀取穩定字段，而不是解析自然語言。

## 一個真實場景

比如你要統計任務數量，就讓指令輸出 JSON，再由腳本讀取 `count` 或列表長度。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裏開始 | 當前頁面標題和主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、訪問記錄或同步進度 | 回到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停下來，確認範圍後再繼續 |

## 邊界

腳本要把錯誤路徑也寫清楚：連線失敗、訪問碼錯誤、沒有數據，應該給出不同提示。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一項輸入、檢查一個狀態、或打開相關設定完成一次確認。
