## 先把它想成什么

把它想成工作台上的便签：先把想法放下来，再决定今天拿起哪一张。

## 一个真实场景

第一次打开 Granoflow 时，先找到收集箱、任務、項目和回顧，不急着配置所有設定。

## 具体用法和边界

想最快开始用 GranoFlow，就先做三件事：新增一个任務，需要时把它連接到項目，晚上用一两句话回顧今天。不需要先搭好完整系统。

### 第一步：先写下一个任務

打开 GranoFlow，点 **+**，写下现在脑中最清楚的一件事。

先不用判断它重不重要，也不用急着决定它属于哪个項目。第一步只是把事情记下来。新任務会先进入收集箱，之后你有时间时再整理。

### 第二步（可选）：需要时連接到項目

如果这件事属于一个更大的方向，比如“完成论文”或“准备搬家”，可以在任務详情里把它連接到对应項目。

这一步不是必须的。你可以先把任務留在收集箱，等項目结构真的有帮助时再整理。

### 第三步：晚上做一次小回顧

一天结束前，打开 GranoFlow，看一眼今天完成了什么、还有什么没完成，然后在日回顧里写一两句话：

- 今天做了什么
- 明天最想推进哪一件事

不用写长篇总结，不用给自己打分，也不用把它变成每天必须完成的压力。它只是帮你把今天、明天和长期目标轻轻连起来。

## 常见误解

| 容易误解 | 更稳的理解 |
| --- | --- |
| 「5 分钟开始」需要一次配置完 | 先完成目前这一步，后续再逐步补充 |
| 頁面里所有入口都要立刻用上 | 只處理和你目前任務有关的入口 |
| 没有马上整理好就是失败 | 只要下一步更清楚，就已经有用 |

::::note[决定仍要回到你的目标]
Granoflow 可以把信息、狀態和下一步摆清楚；要不要繼續、是否改設定、是否刪除或恢復資料，仍要看你目前頁面和真实目标。
::::
