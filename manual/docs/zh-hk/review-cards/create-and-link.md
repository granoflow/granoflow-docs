---
title: 建立與關聯卡片
description: "從任務、回顧或已有經驗裏建立卡片，並把卡片關聯回具體任務。"
---

建立卡片時，先別問「我能不能把這段話存起來」。更好的問題是：**以後遇到類似任務時，我想讓自己先想起哪一句？**

Granoflow 允許你單獨新建卡片，也可以從任務詳情裏加入卡片。兩種入口的目的不同：單獨新建適合整理已經想清楚的經驗；從任務裏加入適合把剛完成、剛回顧出來的判斷綁回原來的工作現場。

## 先寫能被練習的問題

![新建卡片頁](../../screenshots/zh-hk/route-review-card-new-review-cards-new-main.png)
新建卡片頁的重點不是把內容寫長，而是把問題寫清楚。一個好問題應該讓你在練習時能先停一下，自己組織答案。

| 不太適合 | 更適合 |
| --- | --- |
| 「項目管理很重要」 | 「項目延期時，先檢查哪三件事？」 |
| 「收集箱要清空」 | 「什麼情況下任務應該離開收集箱？」 |
| 「回顧有幫助」 | 「完成任務後，哪類經驗值得做成卡片？」 |

答案也不需要像教材。寫成你以後能看懂的一段話就好，最好帶一個真實例子。比如「如果任務已經有項目、日期或下一步，就不要繼續放在收集箱裏；收集箱只放還沒整理清楚的輸入。」

## 從任務裏建立卡片

![任務新增卡片頁](../../screenshots/zh-hk/route-task-review-card-add-tasks-taskid-cards-add-main.png)
任務詳情裏的「任務卡片」區域適合處理剛從行動裏冒出來的經驗。圖中右側是任務詳情，底部有「新增卡片」入口。這個入口的好處是：卡片一開始就知道自己來自哪件事，不會變成孤零零的一條筆記。

可以按這個順序做：

1. 開啟相關任務。
2. 先看任務標題、說明和節點，確認這次真正學到的是什麼。
3. 在「任務卡片」區域新增卡片。
4. 用一句問題抓住下次要提醒自己的點。
5. 用答案寫清楚當時的判斷和例子。

不要把任務說明複製進卡片。任務說明回答「這件事是什麼」，卡片回答「下次遇到類似情況，我要怎麼判斷」。

## 關聯已有卡片

![卡片詳情頁](../../screenshots/zh-hk/route-review-card-temp-import-card-review-cards-temp-imports-tempdeckid-main.png)
卡片詳情頁會顯示卡片題目、來源、學習狀態和關聯任務。圖裡的卡片「什麼是領域？」已經關聯到一個任務。這個關聯很重要：它讓卡片不只是知識條目，而是能回到具體行動的提醒。

卡片詳情更像一張索引卡，不會把整篇筆記重新鋪開。想繼續閱讀完整內容時，展開「原始欄位」，在 `Content` 摘要下點擊 **查看筆記**。筆記會從右側開啟，正文、同一筆記下的其他卡片和關聯任務都集中在這裡；關閉筆記後，你會回到原來的卡片詳情。

如果你已經有一張合適的卡片，就不要再新建一張近似卡片。先打開原卡片，確認它是否能覆蓋這次任務；如果能，關聯即可。如果它只差一點點，可以編輯答案，讓它更像一條可復用經驗。

## 什麼時候不要做卡片

有些內容留在任務或回顧裡更好：

| 情況 | 放在哪裡更好 | 為什麼 |
| --- | --- | --- |
| 一次性的安排 | 任務 | 做完就結束，不需要反覆練 |
| 當天的情緒記錄 | 日記或回顧 | 不適合變成練習題 |
| 大段過程復盤 | 回顧 | 卡片太長會降低練習質量 |
| 帳號、連結、隱私資訊 | 不建議放卡片 | 卡片會被反覆展示和導出 |
| 一句可復用判斷 | 卡片 | 下次能直接幫你做出選擇 |

## 寫卡片時的小標準

一張卡片寫完後，可以用下面四個問題檢查：

| 檢查問題 | 通過標準 |
| --- | --- |
| 問題是否具體 | 看到問題後，知道要回憶哪類判斷 |
| 答案是否能操作 | 不只是道理，而是能指導下一步 |
| 例子是否來自真實任務 | 不是空泛建議，而是你確實遇到過 |
| 是否值得再見一次 | 下次練到它時，你不會覺得浪費時間 |

## 下一步

創建幾張卡片後，不要急着繼續堆數量。去[練習、掌握與內化](./study-and-internalize/)做一輪短練習，看看這些卡片在題面狀態下是否真的能讓你想起答案。
