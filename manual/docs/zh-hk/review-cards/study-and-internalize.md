卡牌練習不是為了證明你記性好。它的作用更樸實：在真正做之前，讓那些已經總結過的經驗重新浮上心頭。

如果你把卡牌當成「每天必須完成的打卡」，很容易變成負擔。更好的用法是：每天做一小輪，把最容易忘記、最可能幫到今天的提醒撿起來。

## 先自己想，再看答案

![卡牌練習題面](../../screenshots/zh-hk/review-card-study-domain-garden-question.png)

題面只顯示問題，是為了留出一個短暫停頓。看到「什麼是領域？」時，先不要急著點答案。你可以在心裏用自己的話答一遍：領域就像人生裏的幾個花園，任務要放回更大的生活版圖來看。

這個停頓很重要。只閱讀答案會讓人產生「我懂了」的感覺，但下次做任務時未必想得起來。先回憶，再校正，效果會扎實很多。

## 根據真實感覺選擇反饋

![卡牌練習背面](../../screenshots/zh-hk/review-card-study-domain-garden.png)

顯示答案後，底部會出現四個反饋按鈕。它們不是情緒評價，而是給下一次練習排隊用的信號。

| 按鈕 | 什麼時候按 | 它表達的意思 |
| --- | --- | --- |
| 遺忘 | 完全想不起來，或答案方向錯了 | 這張卡需要更快再出現 |
| 勉強 | 想起一點，但需要答案幫忙 | 還不穩定，繼續練 |
| 記得 | 基本答對，只是表達不夠順 | 可以按正常節奏繼續 |
| 輕鬆 | 不用費力就能想起，並且知道怎麼用 | 可以隔久一點再出現 |

不要為了讓統計好看而按「輕鬆」。如果一張卡牌在真實任務裏還經常派不上用場，就誠實點「勉強」或「記得」。GranoFlow 不是在考你，它只是在幫你安排下一次提醒。

## 掌握和內化有什麼分別

![卡牌統計](../../screenshots/zh-hk/review-card-statistics-main.png)

統計頁裏的「已掌握」和「已內化」不是獎章。你可以這樣理解：

| 狀態 | 更像什麼 | 你可以怎麼用 |
| --- | --- | --- |
| 未學習 | 剛放進抽屜的提醒 | 先挑今天相關的練 |
| 學習中 | 還需要多見幾次的提醒 | 不急着判斷成敗 |
| 已掌握 | 看到問題能比較穩定地答出來 | 繼續觀察真實任務中是否用上 |
| 已內化 | 不看卡牌也常常能自然想到 | 可以把精力留給更新的經驗 |

一張卡牌真正有價值，不是因為它變成「已內化」，而是因為它改變了你下一次處理任務的方式。例如你開始任務前會自然問：「這件事屬於哪個領域？是不是該放進項目裏？」這就說明它已經從卡牌回到行動。

## 什麼時候練習

你不需要等到狀態很好才練習。最適合的時間通常很短：

| 場景 | 練習方式 |
| --- | --- |
| 開始工作前 | 練 3 到 5 張，幫自己進入狀態 |
| 完成回顧後 | 練和剛才經驗相關的卡牌 |
| 項目推進卡住時 | 搜尋相關卡牌，找以前的判斷 |
| 一天結束前 | 做一小輪，把今天可能用到的提醒收尾 |

如果練習過程中發現一張卡牌總是答不出來，不一定是你沒記住，也可能是卡牌寫得太抽象。回到卡牌詳情，把問題改得更具體，或者在答案裏加一個例子。

## 不要把練習變成壓力來源

卡牌學習應該幫你減輕反覆踩坑的成本，而不是多製造一個待辦清單。今天只練了兩張也沒關係；關鍵是這兩張有沒有幫你想起一個具體做法。

一個實用做法是：練習結束後，揀一張最有用的卡牌，馬上問自己一句：**今天哪件事可以用上它？**如果能回答出來，這次練習就已經落到地上了。
