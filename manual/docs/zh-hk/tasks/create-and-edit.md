---

創建任務時，不需要一次填完所有字段。最小動作只有一個：寫標題並儲存。其他內容可以等任務真的要推進時再補。

更穩的理解是：標題讓事情被記住，日期讓它進入某一天，項目說明它屬於哪個目標，標籤幫助篩選，步驟負責拆小，回顧記錄做完後的經驗。

## 從哪裡創建任務

| 入口 | 適合什麼時候用 | 儲存後的特點 |
| --- | --- | --- |
| 底部 **+** 按鈕 | 想馬上記下一件事 | 沒有日期時進入收集箱 |
| 收集箱裡的輸入區 | 正在整理臨時想法 | 適合連續補充待整理事項 |
| 任務列表的時間分區 | 已經知道大概哪天做 | 會帶上對應日期 |
| 項目或里程碑裡 | 已經知道目標歸屬 | 會帶上項目或階段 |
| 任務詳情的節點區 | 想拆小當前任務 | 成為這條任務的一部分 |

如果你只是怕忘記，直接用 **+** 就好。等之後整理時，再決定它屬於哪一天、哪個項目。

## 字段分別負責甚麼

| 字段 | 是否必填 | 作用 |
| --- | --- | --- |
| 標題 | 必填 | 寫清楚要做甚麼 |
| 描述 | 可選 | 放背景、連結、草稿或說明 |
| 截止日期 | 可選 | 決定任務出現在哪一天 |
| 提醒 | 可選 | 到指定時間通知；不能設在過去 |
| 項目 | 可選 | 說明任務屬於哪個目標 |
| 里程碑 | 可選 | 說明任務屬於項目裏的哪個階段 |
| 標籤 | 可選 | 用來篩選同類任務 |
| 節點 | 可選 | 把大任務拆成小步驟 |
| 任務回顧 | 完成或歸檔後使用 | 記錄實際情況和下次可復用的判斷 |
| 任務卡片 | 項目任務中使用 | 把經驗保存成以後可練習的卡片 |

::::tip[標題先寫成動作]
「論文」太大，「寫論文第三章第一段」更容易開始。標題不一定要長，但最好能讓你知道下一步手要放在哪裏。
::::

## 保存後任務去哪了

任務保存後出現在哪裡，取決於你填了哪些欄位。

| 任務資訊 | 會出現在哪裡 |
| --- | --- |
| 沒有日期 | 收集箱 |
| 有日期 | 對應日期的任務列表 |
| 有項目或里程碑 | 對應項目或階段；如果沒日期，也仍在收集箱 |
| 在項目裡建立 | 預設歸屬到該項目；是否進任務列表仍看日期 |

修改日期、項目或里程碑，不會複製任務。它只是改變同一條任務的檢視位置和歸屬。

## 編輯已有任務

點擊任務就能開啟詳情。任務詳情不只是用來改標題，它負責集中查看和補充這件事的背景資料。

你通常會在詳情裡做這些事：

- 改標題，讓下一步更清楚
- 補日期、提醒、標籤、項目或里程碑
- 在描述裡放背景、連結或草稿
- 用節點拆成幾個小動作
- 查看圖片、附件和相關歷史參考

任務詳情不放「開始專注」和「完成任務」按鈕。做完之後，回到任務列表勾選這條任務的核對框；開始專注則使用應用目前提供的專注入口。

::::note[提醒時間的邊界]
提醒不能設定在已經過去的時間。如果你選了過去時間，系統會提示你重新選擇。
::::

## 標籤模板會不會覆蓋內容

如果你選擇的自訂標籤帶有模板，並且這條任務還沒有描述和節點，GranoFlow 會把模板內容添加到任務描述和根節點裏。

如果任務已經有描述或節點，模板會跳過，避免覆蓋你已經寫好的內容。同一個標籤模板對同一條任務只會自動添加一次；如果模板添加失敗，標籤選擇仍會保留，你可以稍後手動補充。

## 下一步

如果標題裏想直接寫日期、標籤、項目或提醒，繼續看「用自然語言寫任務」。如果任務太大，繼續看「拆解任務」。
