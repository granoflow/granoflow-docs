有時你只想快速記下一件事，不想打開一堆欄位。自然語言輸入就是為這種場景準備的：你可以在標題裡順手寫日期、標籤、項目或提醒，GranoFlow 辨識後會給出候選，等你確認後再寫入對應欄位。

它不是讓你用一句話取代所有編輯。更準確地說，它是建立任務時的快捷入口。

## 一個例子

```text
整理報告 明天 #工作 @論文初稿 ~下午3點
```

這句話裡同時包含了任務標題、日期、標籤、項目或里程碑，以及提醒時間。GranoFlow 會把這些內容辨識成候選項；你確認後，它們才會進入對應欄位。

## 常用寫法

| 你輸入的內容 | 候選含義 |
| --- | --- |
| `#工作` | 加入「工作」標籤 |
| `@論文初稿` | 關聯項目或里程碑 |
| `明天`、`下週五`、`3月5日` | 設定截止日期 |
| `~下午3點`、`~明早9點` | 設定提醒時間 |

確認方式通常是點擊候選，或按 **Enter** / **Tab** 確認目前候選。按 **Escape** 關閉候選後，未確認的文字會繼續留在標題裡。

::::caution[確認前不會寫入]
辨識到的內容不會自動變成標籤、日期、項目、里程碑或提醒。你必須明確確認，才會寫入對應欄位。沒有確認的部分會繼續作為標題文字保留。
::::

## 為什麼要確認

確認步驟看起來多一步，但它能避免誤寫。例如「下週五討論設計」可能只是標題內容，也可能是日期；`@官網改版` 可能指項目，也可能只是你想寫進標題的文字。

GranoFlow 先給候選，再等你確認，就是為了讓最終欄位由你決定。

## 常見限制

| 情況 | 更穩妥的做法 |
| --- | --- |
| `#`、`@`、`~` 黏在奇怪位置 | 放在清楚的詞前，例如 `#工作` |
| 想設定日期 | 直接寫 `明天`、`下週五`，不要用 `@` |
| 複雜句子辨識不準 | 手動打開欄位修改 |
| 候選不是你要的 | 不確認，繼續把它當標題文字 |

自然語言輸入只是省步驟，不是必須使用。辨識結果不對時，直接手動設定欄位就好。
