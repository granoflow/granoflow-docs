行動系統越常用，數據越值得保護。任務、項目、回顧和卡片都承載了你的工作線索。

## 一個真實場景

換電腦前，先看數據管理、同步進度與新設備加入；不要把遷移當成普通登入。

## 換設備前先看這三處

![數據管理](../../screenshots/zh-hk/route-data-management-settings-data-management-main.png)

數據管理適合在遷移、備份或清理前開啟。它回答的是「我能不能帶走或恢復這份數據」。

![同步進度](../../screenshots/zh-hk/route-sync-progress-sync-main.png)

同步進度告訴你當前數據是否還在傳輸。換設備前，如果這裏還沒有完成，先等它結束。

新設備加入同步是最後一步。只有當舊設備和帳號狀態都確認後，再讓新設備進入同一條數據鏈路。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裏開始 | 當前頁面標題和主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、訪問記錄或同步進度 | 回到上一層，按順序排查 |
| 擔心影響數據 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

先保護數據，再追求順手。這個順序在換設備時尤其重要。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一項輸入、檢查一個狀態、或開啟相關設定完成一次確認。
