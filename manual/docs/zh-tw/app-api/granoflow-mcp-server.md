title: Granoflow MCP Server
description: "為支援 MCP 的本機 AI 工具提供 Granoflow 能力。"
---

MCP Server 更適合本機 agent。它把 Granoflow 的能力包裝成工具，讓 AI 可以在你的授權與本機環境裡呼叫。

## 一個真實場景

如果你在本機使用 Codex、Claude Code 或類似 agent，MCP 比複製貼上任務列表更穩定。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 目前頁面標題與主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空白提示、存取記錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

先讓 Granoflow 桌面端與本機介面可運作，再設定 MCP Server。MCP 不是雲端同步功能。

## 與 Connector 的差異

| 專案 | MCP Server | ChatGPT Connector |
| --- | --- | --- |
| 運作位置 | 本機 AI 工具附近 | ChatGPT / 網頁環境 |
| 適合任務 | 本機 agent 自動化、讀寫任務 | 對話式查詢與整理 |
| 關鍵前提 | 桌面端、本機介面、工具設定 | Connector 授權與帳號環境 |

MCP 的優勢是貼近本機工作流程。它也因此更需要你理解本機介面、存取碼與工具權限。
