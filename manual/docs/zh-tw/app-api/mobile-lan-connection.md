區域網路連接多了一層環境：設備必須在同一網路裡，位址要指向桌面端機器，還要有存取碼。

## 一個實際情境

如果手機連不上，先確認手機和電腦是否在同一個 Wi-Fi，再看電腦防火牆和存取紀錄。

## 如何判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 當前頁面標題與主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、存取紀錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

區域網路連接僅適用於受信任的網路。公共網路裡不要隨意開啟存取入口。
