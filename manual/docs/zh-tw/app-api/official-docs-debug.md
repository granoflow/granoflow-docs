---
title: 官方檔案除錯
description: "依照檔案檢查介面連線問題。"
---

除錯時最怕跳過步驟。官方檔案的價值在於提供你一條固定的順序：先看桌面端，再看位址，再看存取碼，再看請求內容。

## 一個真實情境

如果你已經換了好幾種工具都失敗，先回到官方檔案裡的最小請求，確認介面本身可用。

## 如何判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 當前頁面標題與主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、存取記錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

最小可重現請求通過後，再回到具體工具設定。這樣更容易定位問題。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一筆輸入、檢查一個狀態、或開啟相關設定完成一次確認。
