指令參考適合已經知道自己要找什麼的人。請先確認桌面端正在執行，再複製指令。

## 一個真實情境

如果指令沒有回傳預期結果，請先檢查存取日誌與本機介面狀態，不要急著修改腳本。

## 先確認介面，再看指令

![指令列工具設定](../../screenshots/zh-tw/route-command-line-tool-settings-command-line-tool-main.png)

指令列工具設定頁會告訴你本機介面是否可用、位址為何、存取碼在哪裡。指令執行不順時，請先看這裡，而不是先去改腳本。

![存取日誌](../../screenshots/zh-tw/route-local-http-api-access-log-settings-command-line-tool-access-log-main.png)

存取日誌能幫你判斷請求有沒有送達 Granoflow。如果日誌裡完全沒有記錄，問題通常出在位址、連接埠、網路或工具設定；如果有記錄但失敗，再檢查權限與參數。

## 如何判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道從哪裡開始 | 當前頁面的標題與主要入口 | 只選擇與當前目標相關的一項 |
| 操作後結果不對 | 狀態、空提示、存取記錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下來，確認範圍後再繼續 |

## 邊界條件

指令能成功執行的前提是本機服務可用、存取碼正確、請求位址指向當前裝置。

## 使用前提

```bash
granoflow --help
```

如果指令無法使用，請先回到桌面端的安裝與指令列工具設定。指令參考頁僅負責查詢用法，不替代安裝與授權程序。

| 問題 | 先檢查 |
| --- | --- |
| 指令不存在 | CLI 是否已加入 PATH |
| 連線失敗 | 桌面端是否正在執行，本機介面是否已開啟 |
| 回傳未授權 | 存取碼是否正確 |
| 資料為空 | 當前帳號與本機資料是否符合預期 |

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小的動作繼續：記錄一筆輸入、檢查一個狀態、或開啟相關設定完成一次確認。
