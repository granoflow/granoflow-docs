---
title: CLI 如何運作
description: "理解 CLI、本機 HTTP API 和桌面端之間的關係。"
---

CLI 不是另一套資料系統。它只是透過本機介面和正在執行的 Granoflow 桌面端溝通。

## 一個真實情境

當你執行腳本建立任務時，實際資料仍進入 Granoflow；腳本只是換了一種入口。

## 如何判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 目前頁面標題和主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空白提示、存取記錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

如果桌面端沒啟動，CLI 通常也無法完成需要本機介面的操作。先讓應用程式運作起來。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一筆輸入、檢查一個狀態、或開啟相關設定完成一次確認。
