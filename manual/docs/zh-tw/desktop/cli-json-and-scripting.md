---
title: JSON 與指令碼
description: "用結構化輸出連接自動化指令碼。"
---

JSON 輸出適合指令碼讀取，一般文字輸出適合人看。寫自動化時，盡量讓指令碼讀取穩定欄位，而不是解析自然語言。

## 一個真實場景

例如你要統計任務數量，就讓指令輸出 JSON，再由指令碼讀取 `count` 或列表長度。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 目前頁面標題與主要入口 | 只選擇與當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、存取記錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

指令碼要把錯誤路徑也寫清楚：連線失敗、存取碼錯誤、沒有資料，應該給出不同的提示。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一筆輸入、檢查一個狀態、或開啟相關設定完成一次確認。
