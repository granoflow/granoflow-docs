GranoFlow 不是把任務、專案、回顧和卡片分成四個孤立工具，而是把它們接成一條工作流：先把事情收進來，再放回專案和領域；推進之後，用回顧留下判斷；值得重用的經驗，再進入記憶卡片。

這版手冊按目前 macOS 應用、深色橫向截圖和 `final-manual-screenshot-plan.json` 重寫。舊手冊只用作覆蓋檢查，不作為新正文來源。

## 閱讀路徑

1. 先讀 [GranoFlow 在解決什麼問題](getting-started/overview/)，建立整體心智模型。
2. 再讀 [任務](tasks/)，把事情變成可以推進的下一步。
3. 接著讀 [專案與領域](projects/)，把任務放回長期結構。
4. 讀 [回顧](review/)，學習怎樣保留完成過程裡的判斷。
5. 用 [記憶卡片](review-cards/) 完成一次練習。
6. 按需要查 [設定](settings/)、[資料安全](data-security/) 和 [桌面介面](desktop-local-api/)。
7. 遇到異常時，先看 [排查順序](troubleshooting/)。

## 這本手冊怎樣使用截圖

只有通過圖片正常性評審和文件可用性評審的截圖才進入正文。截圖不是裝飾，它必須幫你確認入口、狀態、結果或風險邊界。
