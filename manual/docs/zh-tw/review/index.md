完成一項任務後，裡面仍然可能有值得保留的經驗。回顧用來記錄發生了什麼、你如何判斷，以及下一步是什麼。

## 回顧流程

1. 從剛完成或剛推進的任務開始。
2. 記錄事實：做了什麼、結果如何。
3. 記錄判斷：什麼有效、哪裡卡住、下次要注意什麼。
4. 有下一步時，轉回任務。
5. 會反覆用到的經驗，可以做成記憶卡片。

回顧不是評價自己好壞，只是把事實、判斷和下一步保留下來。
