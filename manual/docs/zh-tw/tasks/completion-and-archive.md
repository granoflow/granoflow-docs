任務從當前列表裡不見了，不一定是丟了。它可能只是完成了、歸檔了、被刪除到回收桶，或者因為日期和篩選條件換了位置。

這一章先把三個狀態分清楚：完成表示事情做完，歸檔表示暫時收起來，回收桶表示刪除後還沒有徹底清空。

## 已完成：保留完成記錄

![已完成列表](../../screenshots/zh-tw/route-completed-main.png)
已完成列表保存已經做完的任務。它不是垃圾桶，而是你的完成記錄：以後做日回顧、補任務回顧、查看某天做過什麼，都會用到這些記錄。

任務完成後通常會：

- 從當前待辦清單中移開
- 記錄完成時間
- 出現在已完成檢視裡
- 用於日回顧統計
- 在詳情裡顯示任務回顧入口

在任務清單勾選核取方塊即可完成任務。如果任務正在專注中，完成動作會先結束目前專注階段，再把任務標為完成，並清掉目前任務。

::::tip[不要急著刪完成記錄]
如果你還想在日回顧裡看到完成記錄，不要把已完成任務當成無用內容刪除。它們是回看一天行動的線索。
::::

## 完成後校準時間

任務剛完成時，系統會記錄一個完成時間。這個時間能讓任務進入已完成檢視和日回顧，但不一定等於真實開始和結束時間。

如果你希望複盤更準確，可以打開已完成任務詳情，進入時間記錄，修改開始時間和完成時間。例如把記錄改成「15:10 開始整理資料，16:05 結束」，而不是只保留點完成按鈕的那一刻。

| 情況 | 是否值得校準 |
| --- | --- |
| 忘了點開始，但實際做了一段時間 | 值得 |
| 忘了及時點完成 | 值得 |
| 只是一個幾分鐘的小任務 | 可以不改 |
| 想讓日回顧裡的时间塊更接近真實 | 值得 |

開始時間必須早於完成時間，完成時間也不能設在未來。日回顧會按任務時間塊計算投入時間；如果兩個任務時間重疊，重疊部分不會重複計算。

## 已歸檔：收起來但保留

![歸檔列表](../../screenshots/zh-tw/route-archived-main.png)
歸檔適合暫時不想在當前列表裡看到、但以後可能還需要知道它存在過的任務。比如舊專案裡的任務、暫時擱置的事項、已經過期但仍有參考價值的內容。

歸檔和完成不是一回事：

| 操作 | 含義 | 是否進入完成統計 |
| --- | --- | --- |
| 完成 | 事情真的做完了 | 會 |
| 歸檔 | 暫時從當前檢視收起來 | 不會 |

已歸檔檢視只處理任務歸檔。卡片歸檔和任務歸檔不是同一件事；要查看已歸檔卡片，需要去卡片管理裡的篩選狀態。

## 回收站：刪除後還能找回

![回收站](../../screenshots/zh-tw/route-trash-main.png)
刪除任務後，它會進入回收站。只要回收站還沒有被清空，你還是可以查看或恢復它。

恢復任務時，如果它原來屬於已經刪除的專案或里程碑，GranoFlow 會讓你選擇：一併恢復原專案和里程碑，或只把任務恢復到收集箱。只恢復任務時，它會變成沒有專案、沒有里程碑、沒有日期的普通收集箱任務，之後可以重新整理。

::::caution[清空回收站前先停一下]
手動清空回收站是不可逆的。如果任務曾經屬於某個專案，或者還有回顧價值，清空後就不能再靠回收站找回。
::::

## 找不到任務時按這個順序查

| 先查哪裡 | 可能原因 |
| --- | --- |
| 當前篩選條件 | 只顯示了今天、某標籤或某專案 |
| 對應日期 | 任務被安排到了某一天 |
| 專案頁面 | 任務被歸入專案或里程碑 |
| 已完成 | 任務已經做完 |
| 已歸檔 | 任務被收起來 |
| 資源回收筒 | 任務被刪除但還沒清空 |

大多數「找不到」，都不是遺失，而是任務去了另一個檢視。

## 重新啟用後的任務回顧

如果你完成任務後寫了任務回顧，之後又取消完成或重新啟用任務，已有回顧不會被清空。未完成時，任務詳情不會顯示任務回顧；任務再次完成或歸檔後，回顧會重新顯示並可以編輯。

## 下一步

任務收尾後，如果有值得複用的經驗，可以繼續看回顧和卡片章節，把一次完成變成以後還能用的判斷。
