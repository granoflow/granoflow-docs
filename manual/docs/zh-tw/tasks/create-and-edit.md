---
title: 建立與編輯任務
description: "建立與編輯任務：先寫標題，再按需要補日期、專案、標籤、步驟和回顧。"
---

建立任務時，不需要一次填完所有欄位。最小動作只有一個：寫標題並儲存。其他內容可以等任務真的要推進時再補。

更穩的理解是：標題讓事情被記住，日期讓它進入某一天，專案說明它屬於哪個目標，標籤幫助篩選，步驟負責拆小，回顧記錄做完後的經驗。

## 從哪裡建立任務

| 入口 | 適合什麼時候用 | 儲存後的特點 |
| --- | --- | --- |
| 底部 **+** 按鈕 | 想馬上記下一件事 | 沒有日期時進入收集箱 |
| 收集箱裡的輸入區 | 正在整理臨時想法 | 適合連續補充待整理事項 |
| 任務列表的時間分區 | 已經知道大概哪天做 | 會帶上對應日期 |
| 專案或里程碑裡 | 已經知道目標歸屬 | 會帶上專案或階段 |
| 任務詳情的節點區 | 想拆小當前任務 | 成為這條任務的一部分 |

如果你只是怕忘記，直接用 **+** 就好。等之後整理時，再決定它屬於哪一天、哪個專案。

## 欄位分別負責什麼

| 欄位 | 是否必填 | 作用 |
| --- | --- | --- |
| 標題 | 必填 | 寫清楚要做什麼 |
| 描述 | 選填 | 放背景、連結、草稿或說明 |
| 截止日期 | 選填 | 決定任務出現在哪一天 |
| 提醒 | 選填 | 到指定時間通知；不能設在過去 |
| 專案 | 選填 | 說明任務屬於哪個目標 |
| 里程碑 | 選填 | 說明任務屬於專案裡的哪個階段 |
| 標籤 | 選填 | 用來篩選同類任務 |
| 節點 | 選填 | 把大任務拆成小步驟 |
| 任務回顧 | 完成或歸檔後使用 | 記錄實際情況和下次可重複使用的判斷 |
| 任務卡片 | 專案任務中使用 | 把經驗保存成日後可練習的卡片 |

::::tip[標題先寫成動作]
「論文」太大，「寫論文第三章第一段」更容易開始。標題不一定要長，但最好能讓你下一步知道手要放在哪裡。
::::

## 保存後任務去哪了

任務保存後出現在哪裡，取決於你填了哪些欄位。

| 任務資訊 | 會出現在哪裡 |
| --- | --- |
| 沒有日期 | 收集箱 |
| 有日期 | 對應日期的任務列表 |
| 有專案或里程碑 | 對應專案或階段；如果沒日期，也仍在收集箱 |
| 在專案裡建立 | 預設歸屬到該專案；是否進任務列表仍看日期 |

修改日期、專案或里程碑，不會複製任務。它只是改變同一條任務的檢視位置和歸屬。

## 編輯既有任務

點擊任務就能開啟詳細資料。任務詳細資料不只是用來改標題，它也是把一件事從「記下來」推進到「正在做」的地方。

你通常會在詳細資料裡做這些事：

- 改標題，讓下一步更清楚
- 補日期、提醒、標籤、專案或里程碑
- 在描述裡放背景、連結或草稿
- 用節點拆成幾個小動作
- 點「專注」，把它設為目前正在做的任務
- 點「完成」，結束任務並留下完成記錄

如果任務還沒有開始，詳細資料底部通常會顯示「專注」和「完成」。點「專注」時，GranoFlow 會把這條任務設為目前任務，並開始一次專注記錄；點「完成」則把它標記為完成。如果任務已經在專注中，詳細資料底部會更強調完成目前任務。

::::note[提醒時間的邊界]
提醒不能設定在已經過去的時間。如果你選了過去時間，系統會提示你重新選擇。
::::

## 標籤範本會不會覆蓋內容

如果你選擇的自訂標籤帶有範本，並且這條任務還沒有描述和節點，GranoFlow 會把範本內容新增到任務描述和根節點裡。

如果任務已經有描述或節點，範本會跳過，避免覆蓋你已經寫好的內容。同一個標籤範本對同一條任務只會自動新增一次；如果範本新增失敗，標籤選擇仍會保留，你可以稍後手動補充。

## 下一步

如果標題裡想直接寫日期、標籤、專案或提醒，繼續看「用自然語言寫任務」。如果任務太大，繼續看「拆解任務」。
