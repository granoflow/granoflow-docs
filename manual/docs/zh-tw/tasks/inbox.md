---
title: 收集箱
description: "收集箱：先把還沒整理的工作放下來，之後再決定日期、專案或刪除。"
---

收集箱不是最終任務列表，也不是專案管理區。它更像一塊臨時桌面：你想到一件事，先放下來，晚一點再決定它是否要安排日期、放進專案，或者直接刪掉。

用好收集箱的關鍵，是把「記錄」和「整理」分開。想到事情時先記錄，真正整理時再判斷。

## 收集箱裡通常是什麼

![收集箱](../../screenshots/zh-tw/route-inbox-main.png)

收集箱顯示的是沒有日期、並且仍然是待辦或進行中的任務。圖裡的重點是「未安排」：這些任務還沒有進入某一天的計畫，所以先停在這裡等你處理。

如果一筆任務已經有日期，它就會去對應日期的任務列表；如果它完成、歸檔或刪除，也會從收集箱消失。

## 怎麼把任務放進收集箱

點底部 **+**，寫下任務標題，然後儲存。只要沒有選擇日期，它就會進入收集箱。

剛記錄時可以寫得很普通：

- 明天聯絡客戶
- 整理課程筆記
- 買牙線
- 週末約朋友吃飯

後面整理時，再把它改成更具體的動作、補日期、放進專案或加標籤。

## 為什麼有些任務不在收集箱

| 你做了什麼 | 任務會去哪 |
| --- | --- |
| 沒選日期，直接儲存 | 留在收集箱 |
| 選了日期 | 出現在那一天的任務列表 |
| 加入專案，但沒選日期 | 仍在收集箱，同時歸屬到專案 |
| 在專案裡建立，但沒選日期 | 仍在收集箱，同時歸屬到專案 |
| 完成、歸檔或刪除 | 離開收集箱，進入對應狀態 |

這裡最容易誤解的是專案歸屬。把任務加入專案，不會單獨讓它離開收集箱；日期才決定它是否進入某一天的任務列表。

::::note[收集箱不是「沒有專案」的列表]
收集箱看的是有沒有日期，不是有沒有專案。一個沒有日期的專案任務，仍然可以出現在收集箱裡。
::::

## 怎麼整理收集箱

整理時不用追求清空。按下面幾個問題處理就夠了：

| 問題 | 如果答案是「是」 | 下一步 |
| --- | --- | --- |
| 需要某天完成嗎 | 是 | 加日期 |
| 屬於某個長期目標嗎 | 是 | 放進專案或里程碑 |
| 太大、不知道怎麼做嗎 | 是 | 拆成步驟 |
| 已經不值得做嗎 | 是 | 刪除或歸檔 |
| 很快能做完嗎 | 是 | 直接做掉 |

::::tip[一個小習慣]
每天開始前看一眼收集箱，把真正重要的任務安排到今天或明天。剩下暫時不急的可以繼續留著，不必強迫自己每天清空。
::::

## 下一步

收集箱裡的內容變清楚後，就可以進入「建立與編輯任務」，給任務補日期、專案、標籤或步驟。
