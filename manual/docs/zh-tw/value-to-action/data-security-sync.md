行動系統越常用，資料越值得保護。任務、專案、回顧和卡片都承載了你的工作線索。

## 一個真實情境

換電腦前，先看資料管理、同步進度與新裝置加入；不要把遷移當成一般登入。

## 換裝置前先看這三處

![資料管理](../../screenshots/zh-tw/route-data-management-settings-data-management-main.png)

資料管理適合在遷移、備份或清理前開啟。它回答的是「我能不能帶走或還原這份資料」。

![同步進度](../../screenshots/zh-tw/route-sync-progress-sync-main.png)

同步進度告訴你當前資料是否還在傳輸。換裝置前，如果這裡還沒有完成，先等它結束。

新裝置加入同步是最後一步。只有當舊裝置和帳號狀態都確認後，再讓新裝置進入同一條資料鏈路。

## 怎麼判斷下一步

| 你遇到的情況 | 先看什麼 | 下一步 |
| --- | --- | --- |
| 不知道該從哪裡開始 | 當前頁面標題與主要入口 | 只選擇和當前目標有關的一項 |
| 操作後結果不對 | 狀態、空提示、存取紀錄或同步進度 | 回到上一層，依序排查 |
| 擔心影響資料 | 備份、同步、帳號或權限說明 | 先停下，確認範圍後再繼續 |

## 邊界

先保護資料，再追求順手。這個順序在換裝置時尤其重要。

## 下一步

讀完這一節後，回到你正在處理的任務，只選一個最小動作繼續：記錄一筆輸入、檢查一個狀態、或開啟相關設定完成一次確認。
